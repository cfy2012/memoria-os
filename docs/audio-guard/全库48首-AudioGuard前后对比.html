指标口径

场景A
音量拉满 2x + 硬钳位（无保护时固件直接把超出 0 dBFS 的样本切平，即"无保护"）。
场景B
过 AudioGuard 保护链：高通 → 音量 2x → 软限幅 0.85 → 热量保护动态压增益。
方波化 %
2x 放大后被硬钳压平的样本占比，越高说明原始素材余量越差、越容易削成方波。
近满幅 %
输出样本幅值 ≥ 0.999 的占比；过 AudioGuard 后全库均为 0.0。
热量增益最低点
持续响度触发热保护后增益压到的谷值。0.5 = 功率减半，1.0 = 未触发。
危险分
= 无保护方波化% + 2 × 低频占比% + 0.5 × 持续顶满秒%。阈值：极危 ≥70 / 高危 ≥40 / 中危 ≥15 / 低危 ≥5。
口径说明：SPOOKY、X-COOL!、MONTAGEM CORAÇÃO、The Invincible King 这 4 首此前用旧口径算过 RMS / 响度 / 动态范围（声道取最大值、1 秒 RMS 块）。本次全库统一按新口径重扫（声道取平均、每秒峰值）。峰值、削波、低频占比、时长与旧数据一致，表中数字一律以新口径为准。
