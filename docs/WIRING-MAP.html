行线：每行 10 颗键左脚并联 → R0~R5 → MCP#1 GPA0~5 ｜ 列线：每列 6 颗键右脚并联 → C0~C3 → MCP#1 GPB0~3，C4~C9 → MCP#2 GPA0~5

⑤ 焊完上电自检（8 步）

步动作预期
1拨开关前插 USB 充电线TP4056 红灯亮 = 充电回路 OK
2拨开关上电背光亮、桌面出现，不无限重启
3看 A 桌面右上角电池图标百分比 ≈ 实测电压（永远 0% = 采样线错）
4拨摇杆焦点在桌面格子间移动（X/Y 反了互换 VRx/VRy）
5按任意键终端出字符；F1~F7 进对应模式
6按"灯带"键灯带亮/换档（全黑 = 查 330Ω 与 DIN 方向）
7进 MUSIC 播 sample/ 下 mp3出声 = I2S 链 OK
8拔 TF 再插回字库加载失败报错 = TF 座接触不良，重焊

⑥ 红牌坑位（焊前看一遍，焊完出问题先查这里）

GPIO33~37 绝对不接东西——Octal PSRAM 内部占用，接了直接崩机
摇杆 VCC 必须 3.3V——5V 供电 ADC 超量程，中位值漂移
MCP #2 A0 忘接 3.3V——两颗芯片同地址 0x20，列 C4~C9 全乱
二极管方向焊反（B 案）——该键永远无反应；排查用自检第 5 步逐键过
灯带 DIN 方向接反——整条不亮；箭头朝数据进入侧
GPIO19/20 不接外设——USB D−/D+ 专用；天线端 15×5mm 周边 5mm 禁金属禁铜
