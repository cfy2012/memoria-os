# 外壳一版过校验清单

> @brief 3D 外壳一次打印成活校验表。设计照表画，送打前照表查。
> 原则：**结构按 v10 推算值定死，数字等实测改**；打印周期长（外部代打），重打成本高，一切以一版过为目标。

## 一、公差铁律（画壳时直接套）

| 类型 | 规则 | 说明 |
|------|------|------|
| 通孔（螺丝/按键/USB） | 标称 **+0.3mm** | FDM 孔收缩，宁大勿小 |
| 卡槽/内腔 | 标称 **+0.2mm** | 模块塞入侧单边留 0.1 |
| 装配缝隙（面壳↔底壳） | **0.2mm** 避让 | 防打印毛边咬死 |
| 卡扣 | **-0.1mm**（过盈） | 卡扣靠弹性，松了没用 |
| 层间悬空 | **2mm**（不含隔板壁厚） | 项目既定铁律 |
| 壁厚 | ≥2mm，加强筋另加 | 太薄必翘 |

## 三、送打前最后一遍（缺一不发）

- ☐ 全部孔位对照实模块比过（或纸模 1:1 比过）
- ☐ 小样试打完成：四角卡扣 + USB-C 开孔条 + 摇杆帽
- ☐ 上表 1~10 实测改数全部落实（无一留"推算"状态）
- ☐ 卡扣方向一致（都从内侧勾，别一半里一半外）
- ☐ 装配顺序心里过一遍：哪层先进、哪颗螺丝后锁
- ☐ 导出 STL 用 verify_stl.py 过校验（流形/法线/尺寸）

## 四、实测当天流程（~10-15 料到）

1. 卡尺量：屏可视区 / 喇叭 / 摇杆帽 / 电池厚（§二标记 ☐ 项）
2. 对照本清单改数（只改数字，结构不动）
3. 纸模比一遍关键孔位
4. 定稿 → 发同学打印
5. 等件期间：焊板（互不阻塞）
