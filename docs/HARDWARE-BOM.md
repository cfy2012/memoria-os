## 三、选型注意事项（与定版一致）

1. **核心板**：选 **45×28 大核心板（带底板排针）**，N16R8（16MB Flash + 8MB PSRAM）。背焊洞洞板：排针 2×17 穿板孔（2.54 对齐），芯片朝底仓下凸 ~7。别买 S3-Zero 小核心板（尺寸不符）。
2. **电池**：必须 **505080 软包（50×80×5）**，容量标称 ~5000mAh（实物 4500~5200 复核）。18650 圆柱直径 18mm 装不进，已排除。**按 PARTS-DIMENSIONS 实测厚度后复核仓尺寸**。
3. **喇叭**：要**方形纸盆**（非圆形），~30×23，8Ω 1~3W；透音孔开在喇叭正对面（壳底）。
4. **轻触键高度**：6×6×2.5 / 6×6×3 矮款，行程 0.25mm。6×6×5 立式长款主板层放不下（净高仅 2mm）。侧键可用余量件。
5. **键盘扩展器**：TCA8418 为 QFN 封装采购不可得，选 **2× MCP23017**（DIP-28 直插，易焊）。地址 A0=0 → 0x20、A0=1 → 0x21，与固件 MCP23017 驱动一致。
6. **洞洞板尺寸**：100×150 双面喷锡，2.54 孔距，1.6 厚。孔数 39×59 或 40×60 均可（键距 10mm 非 2.54 整数倍，键脚插相邻孔+弯外脚，差 1 孔不影响布局）。
7. **外壳**：107×157×20 = 顶盖 2.5 + 壳体 17.5 两件，内部 5 层台阶（底仓/主板托台/屏幕托台）。FDM 打印托台需支撑，打样店用 SLA/SLS 免支撑；或按 `docs/PARTS-DIMENSIONS.md` 自己画。
8. **屏幕引脚**：SPI 12/11/13 + CS10/DC9/RST8/BLK14；横装（长边沿 X），排针朝下。
9. **天线净空**：核心板天线端 5mm 禁金属、禁螺丝压。
10. **焊接顺序**：先电源/地 → 屏幕/摇杆 → 键盘（2× MCP23017 + 100 键 60 上板，焊完逐行测试再封壳）。
11. **键帽**：内嵌式（顶面凹 2mm 指窝），未按压与上壳齐平，行程 0.25mm；键帽 3D 打印或现成计算器键帽，孔位留 0.4~0.5 间隙。

## 五、到货核验清单（焊前必查）

1. 洞洞板数孔（39×59 或 40×60 都行）、量孔径
2. 屏幕含排针实际高度（6~8，影响整机厚度）
3. 电池 505080 实测厚 5、复核容量
4. 摇杆杆帽立起总高实测 ~32
5. 喇叭厚 + 背后留腔 2~3
6. 核心板含排针高 ~5.5、背焊下凸 ~7
