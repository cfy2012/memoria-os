# Memoria OS · 解方程求解器设计（SOLVER-SPEC）

> 起草：2026-10-06 · 豆包-2 · 状态：设计定稿，代码待编译窗口
> 用户需求（原话）："输入式子弹出解，有多少个未知数自己看"——求解器体验，非菜单式选型。

---

## 1. 目标

CALC 模式扩展「解方程」：用户直接输入式子字符串，系统**自动识别未知数个数与次数**，求解并输出。典型交互：

```
输入: 3x+5=20        →  x = 5
输入: x^2-5x+6=0     →  x1 = 3, x2 = 2
输入: 2x+y=5, x-y=1  →  x = 2, y = 1
```

## 2. 支持范围（初中数学，够用为止）

| 类型 | 判别规则 | 求解 |
|------|----------|------|
| 一元一次 | 1 个未知数，最高次数 1 | x = -b/a（a≠0，a=0 报无解/无数解） |
| 一元二次 | 1 个未知数，最高次数 2 | 判别式 Δ=b²-4ac；Δ<0 无实根提示；Δ=0 单根；Δ>0 双根 |
| 二元一次方程组 | 2 个未知数，2 个方程 | 克拉默法则；Δ=0 报无唯一解（平行/重合） |
| （可选）三元一次方程组 | 3 个未知数，3 个方程 | 高斯消元，初中拓展 |

## 3. 输入格式约定

- 未知数字母：`x` `y` `z`（小写；一个式子内同一字母 = 同一未知数）
- 幂次：`x^2` 表示二次；也接受 `2x^2`（系数在前）、`x*x`（连乘=二次）
- 缺项自动补 0：`x^2=4x` → 常数项 0；`2x=8` → 二次/常数项 0
- 系数省略：`x+3=5`（x 系数=1）、`-x=2`（系数=-1）
- 方程组：两行输入（换行分隔），或一行内逗号分隔 `2x+y=5, x-y=1`
- 小数/负数：`0.5x+1.2=3`、`-2x=6`
- 忽略空格

## 4. 解析器设计（C++）

### 4.1 词法扫描（单程）
对每个式子逐字符扫描：
- 数字：`0-9` `.` 累积 → `val` 数值
- 字母：`x/y/z` → 当前未知数记号
- `^`：后跟数字 → 该未知数次数
- 运算符：`+` `-` `*` `/`（`/` 仅支持系数除法，初中不要求多项式除法）
- `=`：等号切分左右两侧
- 项累积：`系数 × 未知数^次数` 归入 `coef[未知数][次数]`，常数项归入 `const`

### 4.2 结构（受内核限制：无 STL 依赖？实盘评估）
- 若可用 C++ 标准库：`std::vector`/`map` 存系数，解析最干净（评估：ESP-IDF 默认 C++ 支持 STL，PSRAM 充足，**可用**）
- 否则：固定数组 `coef[3][3]`（3 未知数 × 次数 0..2）+ 未知数集合位图

### 4.3 判别
- 未知数集合大小 = 1 → 一元：最高次数 1=一次 / 2=二次
- = 2 → 二元一次（超 2 元或高次 → 报"暂不支持"）

### 4.4 求解
- 一元一次：`x = -c/b`（形如 bx+c=0，b=0 报错）
- 一元二次：`Δ=b²-4ac`，分支输出（Δ<0 报"无实根"）
- 二元一次：`Δ=a1*b2-a2*b1`，`x=(c1*b2-c2*b1)/Δ`，`y=(a1*c2-a2*c1)/Δ`，Δ=0 报"无唯一解"
- 输出格式化：`str` 小数处理（去尾 0，负号规范），根式保留平方根形式（初中友好：`x = (5+√1)/2` 形式可选，先输出小数+说明）

## 5. UI 与交互

- 入口：CALC 模式 → 菜单项「解方程」（或 CALC 顶层切换键）
- 输入：键盘输入式子（复用拼音输入法的英文/符号层；`^` 键位映射）
- 输出：解 + 一行判别说明（"一元二次·两个实根"）
- 历史：可上翻上次输入（NVS 或内存变量）
- 错误提示：无法解析/不支持的式子给中文提示，不崩溃

## 6. 实现位置与归属

- **位置**：`memoria_kernel/modes/calc_mode.cpp` 扩展，或独立 `memoria_math` 组件（解析器 + 求解器，calc 模式调用）——建议独立组件，测试方便
- **归属**：豆包-2 认领
- **窗口**：等 GLM 编译窗口（与 P1 双核分工同批或后批）
- **测试**：模拟器/CDP 输入用例矩阵（上表 6 个类型 + 边界：a=0、Δ=0、Δ<0、缺项、负系数、空格）
