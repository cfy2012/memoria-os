## 开篇课：写代码之前，先装一个"程序脑"

你好！在真正动手写第一行代码之前，我想先花一章的时间，跟你聊一件**比语法更重要的事**。

我认为在学习如何编程之前，确定一个编程的思想尤为重要。语法就像笔画，思想就像笔顺——笔画谁都学得会，但笔顺不对，字永远写得又慢又乱。这一章我们不上机，就聊天。聊完你再看后面的代码，会有一种"原来如此"的感觉。

### 一、程序到底是什么：一份写给机器的菜谱

先说结论：**程序 = 数据 + 指令**。

想象你要教一个完全不通人情、但极其听话的机器人做一盘番茄炒蛋。你不能说"看着办，炒个蛋"——它会死机。你得写：

```
食材（数据）：番茄 2 个，鸡蛋 3 个，盐 5 克
步骤（指令）：
1. 打蛋
2. 切番茄
3. 热锅
4. 炒蛋，盛出
5. 炒番茄
6. 倒回鸡蛋，加盐，翻匀
```

这份东西就是"程序"。**数据是食材，指令是步骤**。计算机聪明在算得快，笨在不会自己想办法——它只做你写了的，不会做你想的。记住这句话，它能省你一半调试时间：**计算机不会猜你的心思，它只认你写的字**。

### 二、程序思维的两大流派：面向过程与面向对象

我们可以把编程的思维分成两大块：一块叫**面向过程**，一块叫**面向对象**。

**面向过程**的思路是：把一件事拆成一串步骤，一步一步做。像菜谱，像流水线，像爷爷写的操作手册。先干嘛、后干嘛，清清楚楚。

**面向对象**的思路是：把世界看成一群"小人"，每个小人（叫"对象"）有自己的记性和自己的本事。你不用管小人内部怎么干活，喊一嗓子"小王，把这个文件打印了"就行。这种思路适合做大软件，比如办公套件、游戏引擎。

那 Memoria BASIC 是哪派？——**标准的面向过程**。一个程序就是一串步骤，从第 10 行跑到最后一行，路笔直。别小看它：所有语言最终干的活都是"一步一步算"，面向对象只是管理大工程的组织术。**先用面向过程把"一步一步"练扎实，以后学任何语言都省力**——这是真话，不是安慰。

### 三、三大结构：所有程序都是三块积木

这是本章最重要的一节。1966 年，两位计算机科学家证明了一个漂亮的定理（Böhm–Jacopini 结构化定理）：**任何程序，无论多复杂，都可以只用三种结构拼出来**：

1. **顺序**：从上往下，一句一句执行。菜谱默认就是顺序。
2. **分支**：走到岔路口，看条件选路。"如果鸡蛋没了，就去买；否则直接做。"
3. **循环**：同一件事重复做。"10 个番茄，重复 10 次：切一个。"

就这三种。你以后在 BASIC 里学的 `if` 是分支，`for` 和 `while` 是循环，剩下的全是顺序。所谓"会编程"，本质就是：**会把一个大问题拆成这三种积木的搭法**。

**思想练习 1**（动脑不动手）：把"早上从起床到出门上学"拆成顺序、分支、循环三段。

> 参考答案（不唯一，合理即可）：
> - 顺序：睁眼 → 起床 → 刷牙 → 洗脸 → 背书包。
> - 分支：如果今天是工作日，穿校服；否则穿便装。
> - 循环：重复以下动作直到闹钟被按掉：按掉 → 再睡 5 分钟。（这个循环叫"死循环风险"，你妈是超时保护机制。）

### 四、变量：给数据安的"盒子"

程序里数据要放地方——放的地方叫**变量**。把它想象成贴了名字的盒子：盒子上写着 `score`，里面装着 95；老师改分了，把 95 拿出来换成 98——盒子还是那个盒子，里面的东西换了。

后面第二章我们会跟盒子们正式打交道，这里先记住一个感觉：**变量 = 名字 + 里面装的一个值**。

### 五、我们的语言：为什么有行号这种老古董

Memoria BASIC 是"经典行号 BASIC"：每行代码前面有个行号（10、20、30……），**行号决定执行顺序**。

为什么这么设计？说个冷知识：BASIC 1964 年出生在美国达特茅斯学院，两位教授（凯梅尼和库尔茨）发明它，就是为了让**每个普通学生**都能摸计算机——"Beginner's All-purpose Symbolic Instruction Code"，初学者通用符号指令代码。那个年代没有键盘没有屏幕，程序用**电传打字机**打在纸带上，改中间一行？行号就是定位的页码。所以行号不是古板的遗物，而是那个时代的"行定位器"，今天它反而成了特色：报错能精确到第几行，改哪行指哪行。

### 六、开工前检查单

- 能进 PRGM 模式吗？（程序运行的家）
- 关键字写小写了吗？
- 每行都有行号吗？行号是递增的吗？
- 记住三大结构了吗：顺序、分支、循环。

下一章，我们让屏幕开口说第一句话。

## 0x01 print：让屏幕说第一句话
你好！今天我们来学习真正的第一课：让掌机的屏幕显示出你想说的话。这门功夫的名字叫 `print`。

### 0x01.1 第一个程序
打开编辑器，逐行输入（行号编辑器会自动给，你只管打后面的内容）：

```basic
10 print "hello, memoria!"
20 end
```

然后运行。屏幕上会打出：

```
hello, memoria!
```

恭喜，你已经是程序员了。真不是客套——**写出指令、让机器执行、拿到结果**，这个闭环你已经跑通了。剩下的一切都是把这个循环做花样。

逐行拆解：

- 第 10 行：`print` 是"打印"的意思，把后面括住的东西显示到屏幕上。`"hello, memoria!"` 两头带引号，表示这是一段**原样显示的文字**（术语叫"字符串"）。想打什么就换什么，引号里的内容一个字都不会变。
- 第 20 行：`end` 表示程序结束。没有它程序也会跑到头自动停，但写上它是好习惯，像文章的"完"。

**注意**：引号必须是英文引号 `"`，不是中文引号“”。中文引号程序不认识。这是新手第一大坑，先给你打个预防针。

### 0x01.2 print 能打的远不止文字
数字直接打，算式也会先算后打：

```basic
10 print 1024
20 print 3 + 4
30 print "3+4="
40 print 3 + 4
50 end
```

运行结果：

```
1024
7
3+4=
7
```

看到没？第 20 行打印的不是 `3 + 4` 这五个字符，而是**算出来的 7**。不带引号，机器就把当它当算式；带引号，机器就原样照印。引号就是"照抄开关"。

### 0x01.3 分号与逗号：一句话打好几样
一个 print 想打好几样东西，用分号 `;` 或逗号 `,` 隔开：

```basic
10 print "sum="; 5050
20 print "a", "b"
30 end
```

- **分号**：让内容**紧挨着**接在一起，适合"标签+数值"连排，如 `sum=5050`。
- **逗号**：让内容**分开一段距离**，适合排成一列几样东西。

两者还能混用：`print "x="; x, "y="; y`。至于逗号具体空几格，以真机显示为准，你试一下就有数了。

### 0x01.4 一行干几件事：冒号
冒号 `:` 能把好几条语句挤在同一行，从左到右依次执行：

```basic
10 x = 1 : print x : print "done"
20 end
```

这行先做 `x = 1`，再打印 x 的值，再打印 done。冒号是"然后"的意思。**但别贪多**：一行塞太多事，自己都看不懂；一般一行干一件事，顶多两件。另外每行有长度上限 **96 字节**（约 32 个汉字），超长会写不进去。

### 0x01.5 行号的学问
三件事必须清楚：

1. **行号决定执行顺序**，跟你在编辑器里写它的先后无关。先写了 30 行再补 10 行，程序还是先跑 10 行。
2. 编辑器自动步进 +10（10、20、30……），这个"空隙"是故意留的：想在 20 和 30 之间插一句，编辑器给 25，不用全部重排。
3. 行号要**唯一**。同一行号写两次，是覆盖不是报错——这既是修改老语句的合法手法，也是手滑覆盖新代码的经典事故来源。

> **彩蛋：世界上第一只 bug**
> 1947 年，哈佛 Mark II 计算机出了故障，工程师们翻箱倒柜，最后在继电器里揪出一只飞蛾。格蕾丝·霍珀（后来传奇的女将军程序员）把飞蛾用胶带贴进工作日志，写道："First actual case of bug being found."（发现 bug 的第一个真实案例。）从此程序毛病叫 bug，抓毛病叫 debug。你以后也会天天 debug——欢迎入坑，这不是你的错，是传统。

### 0x01.6 print 的兄弟：uart
还有一个 `uart "text"` 语句，样子和 print 差不多，但输出**不走屏幕，走 USB 串口**——插上电脑，在串口调试工具里能看到。它是你以后排查程序毛病的暗号专线：屏幕上看不出哪步错了，就让程序沿途往串口喊话。现在混个脸熟即可。

### 练习题

**练习 1**（热身）：让屏幕打出你自己的英文名。

> 提示：换掉引号里的内容就行，别忘了引号。

**练习 2**：用**一个** print 语句，打出 `my age is 100`（100 换成你的真实年龄，诚重点）。

> 提示：文字带引号，数字不带，中间用分号连。

**练习 3**：只写一行程序（一个行号），用冒号连出三句 print，依次打出 `1`、`2`、`3`。

> 提示：`语句 : 语句 : 语句`。

**参考答案**：

练习 1：
```basic
10 print "duola"
20 end
```

练习 2：
```basic
10 print "my age is "; 18
20 end
```

练习 3：
```basic
10 print 1 : print 2 : print 3
20 end
```

### 本章小结

- `print` 输出到屏幕；带引号原样照印，不带引号当算式先算后印。
- 分号紧排，逗号分开排。
- 冒号 `:` 一行连多句；每行上限 96 字节。
- 行号决定顺序，编辑器 +10 步进，行号可覆盖修改（小心手滑）。
- `uart` 是往电脑串口喊话的调试专线。
- `end` 收尾，好习惯。

## 0x02 变量：给数据安个家
你好！上一章的程序有个毛病：它只会背台词。你说 `print "hello"` 它就 hello，改一个字都得改程序。真正的程序要能**记住东西、并且让记住的东西变来变去**——这就要请出变量了。

### 0x02.1 盒子与赋值：= 是"变成"，不是"相等"
变量就是**贴了名字的盒子**。往盒子里放东西的动作叫**赋值**，写法用等号：

```basic
10 x = 5
20 print x
30 end
```

第 10 行：拿一个盒子，贴上名字 `x`，把 5 放进去。第 20 行：打印 x——注意 x **不带引号**，所以我们打的是盒子里装的东西（5），不是"x"这个字母。

**划重点**：这里的 `=` **不是数学课的"相等"**，要读成"**变成**"。`x = 5` 读作"x 变成 5"。

为什么？看这个：

```basic
10 x = 5
20 x = x + 1
30 print x
40 end
```

第 20 行在数学课上是不成立的（x 等于 x 加 1？），但在程序里天经地义，读法是："拿出 x 里的 5，加 1 得 6，再塞回 x 盒子"。运行后打印 `6`。**盒子里的东西可以被拿出来算一算再放回去**——这个动作是编程的心跳，几乎所有程序都在反复做它。

再记住一条规则：**赋值会覆盖**。盒子里原来是 5，你 `x = 100`，5 就没了。旧值不留底。

### 0x02.2 数值盒子：小数整数都能装
装数字的变量（叫**数值变量**）内部用的是 double 类型——整数、小数都能装，精度大约 15~16 位有效数字，日常随便用。所以下面这些都合法：

```basic
10 a = 3
20 b = 3.14
30 c = a + b
40 print c
50 end
```

打印 `6.14`。

> **彩蛋：为什么叫"浮点"**
> 小数在计算机里的学名是"浮点数"（floating point）：小数点的位置会"浮动"来换取大范围的表示精度。double 是"双精度浮点"，64 个二进制位精打细算分出来的。代价是：某些小数存得不是绝对精确（比如 0.1 其实是 0.1000000000000000055…），所以别用 `=` 去比较两个算出来的小数是否"相等"，那是个经典陷阱——以后你自然会踩到，先留个印象。

### 0x02.3 字符串盒子：带 $ 的变量
装文字的盒子，名字末尾要带个 `$`（美元符号，老 BASIC 用它标记"这是串"）：

```basic
10 name$ = "duola"
20 print "hi, "; name$
30 end
```

打印 `hi, duola`。

变量命名规矩：
- 字母开头，后面字母数字随便（`name$`、`score`、`x2` 都行）。
- **大小写不敏感**：`name$` 和 `NAME$` 是同一个盒子。官方风格统一**全小写**。
- 起名要见名知意。`score` 好过 `s`，`name$` 好过 `n$`——三个月后的你会感谢现在的你。

### 0x02.4 let：可有可无的开场白
老 BASIC 赋值要写 `let`：

```basic
10 let x = 5
```

我们的解释器两种都认：`let x = 5` 和 `x = 5` 完全等价。`let` 可省，直接裸赋值更简洁。看别人老程序遇到 `let` 不用慌，认得就行。

### 0x02.5 交换两个盒子：经典思维题
题目：盒子 a 装着 1，盒子 b 装着 2，请把它们对调。

```basic
10 a = 1
20 b = 2
30 a = b
40 b = a
50 print a, b
60 end
```

先自己想三秒钟再往下看——这样写对吗？

**错了**。第 30 行 `a = b` 一执行，a 里的 1 就被 2 **覆盖**了，1 彻底丢失；第 40 行 `b = a` 拿回来的还是 2。结果两个盒子都是 2。

正确做法：**再要一个盒子当中转**。好比左手啤酒、右手可乐想互换，必须先找张桌子把其中一杯放下：

```basic
10 a = 1
20 b = 2
30 t = a
40 a = b
50 b = t
60 print a, b
70 end
```

打印 `2       1`。这个"临时变量中转交换"是编程的百年老招，值得记住。

### 0x02.6 累加器：程序的记忆艺术
再看一种重要套路——**累加器**：

```basic
10 s = 0
20 s = s + 5
30 s = s + 8
40 print "sum="; s
50 end
```

s 从 0 开始，两次"自己吃自己"后变成 13。别看它土，**求和、计数、收集用户输入**，全是这个骨架。程序里最常用的十行代码，累加器占三行。

### 0x02.7 一条提前立好的铁律：串与数不混算
数字盒子和文字盒子**不能直接混合运算**。`"身高" + 180` 这种写法是不行的——BASIC 会拒绝或出错。想把数字拼进文字里，得先把数字**变成文字**（用 `str$()` 函数，0x31 正式教）。现在先立规矩：**见到 `$` 的是文字，不见 `$` 的是数字，两家来往必须"过海关"**。

### 练习题

**练习 1**：把你的年龄存进变量 `age`，打印 `i am xx years old`（xx 是变量里的值，不许硬抄数字进引号）。

> 提示：文字引号、变量裸写、分号连接。

**练习 2**：把英文名存进 `n$`，打印 `hi, xxx!`（xxx 用变量拼出来）。

> 提示：`"hi, "` 和 n$ 都是文字，文字拼文字用 `+`。两个串拼一起：`"hi, " + n$`。

**练习 3**：a=10、b=99，交换后打印。要求先打印交换前的，再打印交换后的。

> 提示：中转盒子 t。打印两个变量用逗号。

**练习 4**（体验重复之痛）：用累加器算 1+2+3 的和并打印。**不许用循环**（下一章才学），老老实实写三行加法。

> 提示：s = s + 1，然后 s = s + 2，然后 s = s + 3。写的时候感受一下：要是算 1 加到 100 呢？——这个痛苦就是下一章的引子。


练习 4：
```basic
10 s = 0
20 s = s + 1
30 s = s + 2
40 s = s + 3
50 print s
60 end
```

### 本章小结

- 变量 = 名字 + 盒子；`=` 读"变成"，会覆盖旧值。
- `x = x + 1` 是"拿出、加工、放回"，程序的心跳。
- 数字变量随便装（double）；文字变量带 `$`。
- 变量名小写、见名知意；`let` 可写可不写。
- 交换必用临时变量；累加器 s = s + i 是万能骨架。
- 串与数不混算，铁律。

下一章，我们让数字真正"干活"：运算符和一大排数学函数。

## 0x03 运算符与数学函数：让数字干活
你好！今天我们来学习让数字真正"干活"的一章。变量会装东西了，但光装不算，那盒子就是个抽屉。这一章我们给程序装上计算器，顺便认识一大排随叫随到的数学函数。

### 0x03.1 四则运算：+ - * /
加减乘除直接写，和数学课一样：

```basic
10 a = 7
20 b = 2
30 print a + b
40 print a - b
50 print a * b
60 print a / b
70 end
```

结果依次是 `9`、`5`、`14`、`3.5`。乘法用星号 `*`，除法用斜杠 `/`——键盘上就这么俩符号，习惯就好。

**优先级**也和数学课一样：先乘除、后加减，括号最优先。拿不准就加括号，多打两个字符，换一个确定无误——血赚。

```basic
10 print 2 + 3 * 4
20 print (2 + 3) * 4
30 end
```

打印 `14` 和 `20`。看到差别了吧。

### 0x03.2 比较运算：得到"真"和"假"
除了算大小，我们还要**比大小**。比较运算符六个：

| 写法 | 意思 |
|---|---|
| `=` | 等于（在 if 条件里是比较） |
| `<>` | 不等于 |
| `<` | 小于 |
| `>` | 大于 |
| `<=` | 小于等于 |
| `>=` | 大于等于 |

比较的结果是个**数值**：成立得 1（真），不成立得 0（假）。所以在 BASIC 眼里，"比较"也是一种算术。`3 > 2` 的值是 1，`3 < 2` 的值是 0。

注意 `=` 一符两用：在 `x = 5` 这种**赋值位置**是"变成"；在 `if x = 5` 这种**条件位置**是"比较等于"。语境决定身份，读程序时留个心眼。

### 0x03.3 非 0 即真：BASIC 的世界观
BASIC 判断条件只有一条天规：**非 0 即真**。0 是假，其他任何数都是真。所以 `if 5 then print "hi"` 也会打印——5 不是 0，就是真。这个设定马上会派上大用场。

### 0x03.4 没有"并且、或者"，怎么办：算术组合逻辑
很多语言有 `and`（并且）、`or`（或者）关键字。**我们 BASIC 没有**。但有更妙的土办法——利用"真=1、假=0"做算术：

- **并且**：乘起来。`(a > 0) * (b > 0)`——两个都真，1×1=1；有一个假，乘出 0。
- **或者**：加起来。`(a > 0) + (b > 0)`——结果不是 0 就是真（一个真=1，两个真=2，反正非 0 即真）。
- **取反**：用 1 减。`1 - (a > 0)`——原来是 1 变 0，原来是 0 变 1。

```basic
10 a = 5
20 b = -3
30 if (a > 0) * (b > 0) then print "both positive" else print "not both"
40 end
```

打印 `not both`。这套"用乘加代替并且或者"的功夫是本语言的招牌思维，后面章节会反复用。

### 0x03.5 数学函数全家桶
解释器内置一排数学函数，直接写名字加括号就能用：

| 函数 | 意思 | 例子 |
|---|---|---|
| `abs(x)` | 绝对值 | `abs(-5)` → 5 |
| `sqr(x)` | 平方根 | `sqr(9)` → 3 |
| `int(x)` | 取整（朝零截断） | `int(2.9)` → 2 |
| `sin(x)` `cos(x)` `tan(x)` | 三角函数（**弧度制**） | `sin(0)` → 0 |
| `log(x)` | 自然对数 ln | `log(1)` → 0 |
| `log10(x)` | 常用对数 lg | `log10(100)` → 2 |
| `exp(x)` | e 的 x 次方 | `exp(0)` → 1 |
| `pow(a, b)` | a 的 b 次方（必须两个参数） | `pow(2, 10)` → 1024 |
| `rnd()` | 随机数，0 到 1 之间 | 每次不一定 |

三个使用注意：

1. **int 是截断不是四舍五入**：`int(2.9)` 得 2，`int(2.1)` 也得 2，`int(-2.1)` 得 -2——直接砍掉小数部分，朝零取整。想四舍五入？土办法：`int(x + 0.5)`（正数适用）。
2. **三角函数用弧度**：`sin(30)` 不是 30 度！30 度要换算成弧度：`30 * 3.14159 / 180`。数学课的 π=180°，别忘。
3. **幂运算写 `pow(a, b)`**：不支持 `^` 符号。2 的 10 次方写 `pow(2, 10)`。

> **彩蛋：机器不会掷骰子**
> `rnd()` 的"随机"其实是**伪随机**：计算机按一个固定公式，从上一个数算出下一个数，看着乱、其实有谱。真·随机要从物理世界抓噪声。不过对游戏来说，伪随机完全够用——反正玩家也看不出来。（真想知道下一个数是多少的话，那是数学系的事了。）

### 0x03.6 随机数的正确打开方式
`rnd()` 出的是 0 到 1 之间的小数，怎么变成"掷骰子"？三步加工：

```basic
10 r = int(rnd() * 6) + 1
20 print r
30 end
```

拆开看：`rnd()` 在 0~1 → `rnd() * 6` 在 0~6 → `int(...)` 砍成 0、1、2、3、4、5 → `+ 1` 变成 1~6。**"先乘范围、再 int 取整、最后 +1 对齐起点"**，这个配方能造任何区间的随机整数：1~100 就是 `int(rnd() * 100) + 1`。0x81 猜数字游戏全靠它。

### 0x03.7 实战：一个小计算器
把本章的活儿串一串：

```basic
10 a = 3
20 b = 4
30 c = sqr(a * a + b * b)
40 print "hypotenuse="; c
50 end
```

这是勾股定理：两条直角边 3、4，斜边算出来 5。`a * a + b * b` 是"3²+4²"，开方得 5。看到了吗——**一行程序能装下一整个数学公式**，变量就是公式里的字母。

### 练习题

**练习 1**：输入华氏温度变量 f = 100，换算成摄氏度打印。公式：摄氏 = (华氏 - 32) * 5 / 9。

> 提示：一行赋值搞定换算，再 print。

**练习 2**：直角三角形两直角边 a=5、b=12，打印斜边长。

> 提示：照抄 3.7 的配方，换数字。

**练习 3**：掷 6 次骰子并打印 6 个点数。**不许用循环**（下一章才学），写 6 行。

> 提示：`int(rnd() * 6) + 1` 复制六遍。再体会一次"重复之痛"——这已经是第三次了，下一章终结它。

**练习 4**：变量 a=8、b=-2、c=3。用一行 if 判断"三个数是否**全为正**"，全正打印 `all positive`，否则打印 `no`。

> 提示：三个条件连乘。

**参考答案**：


### 本章小结

- 四则 `+ - * /`；先乘除后加减，拿不准加括号。
- 比较结果是数：真 1 假 0；`=` 在条件位置是"比较"。
- **非 0 即真**是唯一天规。
- 并且用乘、或者用加、取反用 1 减——算术组合逻辑。
- `int` 截断取整；三角用弧度；幂用 `pow`。
- 随机整数配方：`int(rnd() * n) + 1`。

## 0x11 input：程序开口问
你好！到今天为止，我们的程序都是"自说自话"：所有数据写死在代码里。今天我们让程序**开口向用户要数据**——交互，是"程序"和"算式"的分水岭。

### 0x11.1 input x：摇杆调一个数
```basic
10 print "set your number"
20 input x
30 print "you set "; x
40 end
```

运行到第 20 行，程序**停下来等你**。调数值用摇杆：

- **上/下**：±1（一个一个挪）
- **左/右**：±10（十个十个跳）
- **按下**：确认，程序继续跑

为什么这么设计？掌机上没有完整键盘（有键盘区的机型，键盘另有重用），摇杆是随身可靠的"旋钮"。想输入 87：右 8 次、下 3 次，按下收工。

程序恢复后，你确认的数就装进了 x 盒子，第 30 行照常打印。

### 0x11.2 input a$：键盘打一行字
要输入文字，用**带 $ 的变量**接：

```basic
10 print "what is your name?"
20 input n$
30 print "hi, "; n$
40 end
```

运行到 20 行，屏幕出现录入框：**英文直接敲，中文自动调起拼音输入法**（方向键选字、Enter 上屏），按 Enter 确认。中文英文都能收——`input a$` 可以收中文名、中文句子，这是 chat 之类中文程序的入口。

### 0x11.3 问完必须"接住"
input 后面必须跟一个变量——它是"接球的手套"。`input x` 接数，`input a$` 接文字。接错手套类型会出乱子，数就给数盒子，文字给串盒子。

### 0x11.4 实战：电子门牌
```basic

20 input n$
30 print "how old are you?"
40 input age
50 print "hi "; n$; ", age "; age
60 print "next year: "; age + 1
70 end
```

先问名字（串），再问年龄（数），最后连报带算。注意第 60 行：print 里可以直接放**算式** `age + 1`，先算后印。交互+计算+输出，一个完整小应用诞生了。

> **彩蛋：对话是程序的专利**
> 1966 年，世界上最早的聊天程序 ELIZA 诞生，它只会把你说的话换个花样反问你（你说"我难过"，它问"为什么难过"），却让无数人以为它懂自己——心理学界都惊动了。今天你学的 input + print，正是 ELIZA 的全部骨架：问一句、接住、加工、反问。0x83 完我们真做一个。

**练习 1**：让用户摇杆输入两个数 a 和 b，打印它们的和、差、积。

### 本章小结

- `input x`：摇杆调数（上下 ±1、左右 ±10、按下确认）。

- print 里可以直接放算式。
- input 是程序与用户对话的起点：问、接、算、答。

## 0x12 if：程序的岔路口
你好！今天我们来学习三大结构的第二块：**分支**。开篇课说过，任何程序都是顺序、分支、循环搭的——今天拿下分支，三大结构就集齐两块了。

### 0x12.1 最简单的 if：满足才做
```basic
10 x = 5
20 if x > 3 then print "big"
30 print "done"
40 end
```

第 20 行读作："如果 x 大于 3，**那么**打印 big"。x 是 5，条件成立，打印 big；接着 30 行照常执行，打印 done。

把第 10 行改成 `x = 1` 再跑：条件不成立，20 行的 print **整句跳过**，直接打印 done。这就是分支——**条件说了算，不成立就当没看见**。

语法骨架：

```
if 条件 then 语句
```

条件就是0x03 的比较运算（`x > 3`、`a$ = "tom"`），或者任何"非 0 即真"的表达式。

### 0x12.2 else：另一条路
两头都安排上：

```basic
10 x = 1
20 if x > 3 then print "big" else print "small"
30 end
```

条件成立走 then 后面，不成立走 else 后面，**两条路必走其一，也只走其一**。

### 0x12.3 大规矩：if 独占一整行
if 是个"一行人士"：**整条 if 必须写在一行内**，不能用冒号拖到下一行去。但 then 和 else 的身体里，**可以**用冒号装多条语句：

```basic
10 score = 75
20 if score >= 60 then print "pass" : print "nice" else print "fail" : print "work hard"
30 end
```

成立就连续打印 pass、nice；不成立连续打印 fail、work hard。不过劝你克制：一行塞四件事已经到舒适上限了。再多，就该用0x51 的 gosub 把活儿搬进"抽屉"。

### 0x12.4 隐藏招式：then 后面跟纯数字 = 跳转
这是老 BASIC 的传统艺能：

```basic
10 x = 0
20 if x = 0 then 100
30 print "not zero"
40 end
100 print "zero!"
110 end
```

第 20 行的 then 后面是个**纯数字 100**——意思不是打印 100，而是**跳到行号 100 去执行**（等于隐形的 goto）。x 等于 0，程序直接飞到 100 行打印 zero!，30、40 行根本没跑。

什么时候好用？条件满足时"翻页"去另一段流程。注意目标行号必须真实存在，跳去一行不存在的代码是新手高频事故。

### 0x12.5 组合条件与多层岔路
复习0x03 ：并且用乘、或者用加。多层岔路（比如成绩分等级）用 if 连环：

```basic
10 score = 85
20 if score >= 90 then print "A"
30 if score >= 60 then if score < 90 then print "B"
40 if score < 60 then print "C"
50 end
```

第 30 行是"if 套 if"：先看是否 ≥60，是的话再看是否 <90——两关都过才打印 B。（我们的一行 if 装不下 else if 这种写法，连环 if 是标准替代。）想更清爽也可以倒着排：先判最高档，命中就跳走（then 数字），后面的 if 自然不再命中——这招0x81 综合项目会用。

### 0x12.6 字符串也能比
if 里比文字完全合法，规则是：**条件两侧只要有一边是串（串变量或带引号的串），就按字符串比较**：

```basic
10 print "password?"
20 input p$
30 if p$ = "open" then print "welcome" else print "denied"
40 end
```

等于 `=`、不等于 `<>` 最常用。`> <` 也能用，按**字节序**比——即逐个字符比编码大小。这带来两个冷知识：

- 大写字母排在小写字母**前面**（A 的编码 65，a 是 97），所以 `"Apple" < "apple"` 成立。
- 比较从第一个字符开始逐位比，像查字典排音序。

### 0x12.7 没有 mod：奇偶判断自己造
判断奇偶要"除以 2 取余数"，但 BASIC **没有取余运算符（mod）**。自己造：一个数减掉"它除以 2 取整再乘 2"，剩下的就是余数：

```basic
10 x = 7
20 if x - int(x / 2) * 2 = 1 then print "odd" else print "even"
30 end
```

拆解：x=7 → 7/2=3.5 → int 得 3 → ×2 得 6 → 7-6=1 → 余 1 → odd。这招叫"**没有工具自己打一把**"，编程日常。顺手记住这个配方：`x - int(x / n) * n` 就是"x 除以 n 的余数"。

> **彩蛋：AI 会作弊**
> 1997 年深蓝战胜国际象棋世界冠军卡斯帕罗夫。老卡赛后坚称第九局有一步"太有人味"，一定是人类棋手 intervenes——其实那正是纯机器走的一步。if 分支堆得足够多、足够巧，程序的行为会"像"有智慧。你写的每个 if 都在给程序的"人格"添砖——将来你的掌机程序什么脾气，全看你怎么写分支。

### 练习题

**练习 1**：摇杆输入一个数，打印它是正数、负数还是零（三种结果）。

> 提示：三条 if 排队：>0、<0、=0，各配各的 print。

**练习 2**：摇杆输入两个数，打印**较大**的那个（如果相等，打印其中任意一个都行）。

> 提示：then 体内可以冒号连两句。

**练习 4**（跳转招式）：x = 5。如果 x 不等于 0，跳到 100 行打印 `got value` 后结束；等于 0 就原地打印 `zero` 再结束。要求用到 "then 数字" 跳转。

> 提示：if x <> 0 then 100。100 行写 print 和 end。

**参考答案**：

练习 1：
```basic

```


### 本章小结

- `if 条件 then 语句 else 语句`；成立走 then，不成立走 else，必走其一。
- **if 独占一行**；then/else 体内可冒号连多句。
- then 后跟纯数字 = 跳转到该行号（目标行必须存在）。
- 组合条件用乘（并且）加（或者）；多层岔路用连环 if。
- 串比较：有一边是串就按串比，`> <` 按字节序（大写在前）。
- 没有 mod：`x - int(x / n) * n` 自己造余数。

三大结构还差最后一块：循环。下一章 `for`，终结"重复之痛"。

## 0x21 for：知道次数的重复
你好！今天我们来学习三大结构的最后一块：**循环**。前几章你已经三次体验"复制粘贴同一段代码"的痛苦了——今天，痛苦终结。知道要重复多少次的时候，用 `for`。

### 0x21.1 语法：for ... next
```basic
10 for i = 1 to 5
20   print "round "; i
30 next i
40 end
```

运行结果：

```
round 1
round 2
round 3
round 4
round 5
```

逐块拆解：

- `for i = 1 to 5`：开一个循环。`i` 叫**循环变量**，从 1 数到 5，每圈数一次。
- 中间的行（20 行）叫**循环体**，每圈执行一遍。
- `next i`：一圈结束，i 加 1，回到 for 检查——没数到头就再来一圈，数到头就出循环。

三行骨架干成了你之前复制六行干的事。**这就是循环的力量：一次写好，N 次享用。**

> **彩蛋：为什么循环变量都叫 i**
> i 是 index（索引）或 iteration（迭代）的首字母。从 1957 年的 FORTRAN 起，`i, j, k` 就是循环变量的"默认工号"——数学家早先也给求和下标记 i。所以全世界的程序员看到 `for i` 都会心一笑：老熟人了。如果一层循环不够用，第二层就轮到 j，第三层 k。

### 0x21.2 step：不按 1 数
`to` 后面还能跟 `step`，指定每圈加多少：

```basic
10 for i = 2 to 10 step 2
20   print i
30 next i
40 end
```

打印 `2 4 6 8 10`——从 2 数到 10，每步 +2。step 2 就是"隔一个数一个"。想数偶数、倍数、单号，step 一句话的事。

**step 省略时默认为 1**。本书示例只保证正步长写法；想"倒着数"（10 数到 1），用下一章的 while 更稳妥。

另外提醒：循环变量 i 就是个普通变量，循环体里可以用它（第 20 行的 `print i` 就在用），甚至能改它——但改了会扰乱计数，新手期别碰。

### 0x21.3 缩进：给谁看的
注意上面例子 20 行前面空了两格。**BASIC 根本不看缩进**——它只认行号。缩进是写给人看的：循环体往里缩一格，一眼看出"这几行是循环里面的"。书上的例子保持这个习惯，你写大程序也保持，纯赚不亏。

### 0x21.4 嵌套：循环套循环
循环体里再开一个循环，叫**嵌套**。经典案例——九九乘法表的核心：

```basic
10 for i = 1 to 3
20   for j = 1 to 3
30     print i; "x"; j; "="; i * j
40   next j
50 next i
60 end
```

跑起来：i=1 时，j 把 1、2、3 走一圈；然后 i=2，j 再走一圈……外层走 1 圈，内层走满 3 圈，共 9 行输出。**嵌套的本质是"对每一种组合都干一遍"**——外层是行，内层是列，铺满整个棋盘。

配套规矩：里外层的 next 要按"先进后出"配对——内层 `next j` 在前，外层 `next i` 在后，别交叉。

### 0x21.5 实战一：1 加到 100
```basic
10 s = 0
20 for i = 1 to 100
30   s = s + i
40 next i
50 print "sum="; s
60 end
```

打印 `sum=5050`。累加器 + 循环，这是编程界第一对黄金搭档。

> **彩蛋：高斯的快捷方式**
> 传说数学家高斯小学时被罚算 1 加到 100，别的人埋头苦加，他几秒钟写出答案 5050：首尾配对，1+100、2+99、3+98……每对都是 101，共 50 对，101×50=5050。循环替你"苦加"，公式替你"取巧"——两者都会，你既像工程师又像数学家。

### 0x21.6 实战二：文字进度条
循环还能攒字符串（攒串的完整原理0x31 细讲，先看着玩）：

```basic
10 bar$ = ""
20 for i = 1 to 10
30   bar$ = bar$ + "#"
40   print bar$
50 next i
60 end
```

每圈往 bar$ 后面追加一个 `#`，屏幕上打出 1 个 #、2 个 #……10 个 #，像一根进度条逐格长满。**循环 + 累加**，连文字都能"生长"。

### 练习题

**练习 1**：打印 1 到 10 每个数的平方（1、4、9……100）。

> 提示：for i = 1 to 10，print 里写 i * i。

**练习 2**：计算 5!（阶乘：1×2×3×4×5 = 120）并打印。

> 提示：把累加器的 `+` 换成 `*`，s 从 1 开始（别从 0 开始——0 乘什么都 0，经典事故）。

**练习 3**：打印 7 的 1 倍到 5 倍（7、14、21、28、35）。要求用 step 一步到位。

> 提示：for i = 7 to 35 step 7。

**练习 4**：先摇杆输入 n（0x11 input），再计算 1+2+…+n 的和并打印。

> 提示：for 的 to 后面可以放变量：for i = 1 to n。程序先 input 后 for。

**参考答案**：

练习 1：
```basic
10 for i = 1 to 10
20   print i * i
30 next i
40 end
```

练习 2：
```basic
10 s = 1
20 for i = 1 to 5
30   s = s * i
40 next i
50 print s
60 end
```

练习 3：
```basic
10 for i = 7 to 35 step 7
20   print i
30 next i
40 end
```

练习 4：
```basic
10 print "n?"
20 input n
30 s = 0
40 for i = 1 to n
50   s = s + i
60 next i
70 print "sum="; s
80 end
```

### 本章小结

- `for i = a to b step c` ... `next i`：知道圈数的重复。
- step 省略默认 1；循环体缩进是给人看的。
- 嵌套 = 穷举所有组合；next 配对先进后出。
- 累加器 + 循环 = 黄金搭档；乘法累加从 1 起（别从 0）。
- to 后面可以放变量。

## 0x22 while：不知道次数的重复
你好！上一章的 `for` 有个前提：你得**先知道圈数**。可现实中很多重复事先数不出来——"吃到饱为止""连上 WiFi 为止""猜中为止"。这种"看情况"的循环，用 `while`。

### 0x22.1 语法：while ... wend
```basic
10 x = 1
20 while x < 100
30   print x
40   x = x * 2
50 wend
60 print "end, x="; x
70 end
```

运行结果：

```
1
2
4
8
16
32
64
end, x=128
```

逐块拆解：

- `while x < 100`：每圈开头**先检查**条件。成立就进循环体，不成立就跳到 wend 之后。
- 循环体里 `x = x * 2` 每圈翻倍——**必须有人推动条件变化**。
- `wend`（while end 的缩写）：循环体的终点，跳回 while 再检查。

第 60 行打印的 x 是 128：最后一次检查时 x 已是 128，不小于 100，循环退出。看懂这个 128，你就看懂了 while 的检查时机。

**while 的灵魂一句话：循环体里必须干点让条件"趋向结束"的事**（本例是 x 翻倍），否则条件永远成立——那就是死循环了。

### 0x22.2 for 还是 while？一道选择题
- **知道圈数**（10 次、100 个、嵌套铺格）→ `for`
- **不知道圈数**（等连接、等猜中、翻倍到某数）→ `while`

拿不准就问自己："圈数写死在 to 后面合理吗？"合理用 for，不合理用 while。两者还能互换着写，但各干各的活最顺手。

### 0x22.3 死循环与保险丝：超时保护
`while 1` 是恒真条件（非 0 即真），写出这种程序就**永远转下去**：

```basic
10 while 1
20   print "tick"
30 wend
```

别慌——系统给你上了保险丝：**每个程序最多执行 100000 步，超限强制终止**，屏幕报"超时保护"。所以最坏情况也不是死机，是程序被"拔电"。上面这个程序打一阵 tick 后就会被收走。

保险丝是保命的，不是用来依赖的：**发布给别人用的程序，循环条件必须能正常结束**。你私自玩 `while 1` 没事，上架程序靠保险丝收尾会被用户骂。

> **彩蛋：电磁炉同款设计**
> 超时保护和电磁炉"干烧断电"是同一种工程哲学：不听话宁可停机，也不烧锅。你以后设计任何"会自动跑的东西"（程序、机器人、闹钟），都要问一句：它卡住了，谁拉闸？

### 0x22.4 实战：翻倍超过 1000
```basic
10 x = 1
20 while x <= 1000
30   x = x * 2
40 wend
50 print x
60 end
```

打印 `1024`。1、2、4……一路翻到第一个超过 1000 的数。这个"**直到超过某值才停**"的结构，while 一眼写出来，for 反而费劲——体会到了吧。

### 0x22.5 实战：带超时的等 WiFi
联网程序第一步是等 WiFi 连上——这活儿天生 while（不知道几秒连上）。但直接写 `while wifistat() = 0 : wend` 有隐患：万一 WiFi 永远连不上，循环就靠保险丝收场，很丢人。职业写法是**自己带计数超时**（WiFi 由系统设置连好，程序只等状态变 1）：

```basic
10 t = 0
20 while wifistat() = 0
30   t = t + 1
40   if t > 50000 then print "wifi timeout, 去系统设置连网" : end
50 wend
60 print "wifi ok"
70 end
```

每空转一圈 t 加 1，t 超过 5 万次（大约几秒）就主动放弃。**"等，但给等待设个死线"**——这是所有联网程序的标准开场，0x61 、0x83 都直接搬它。记住骨架：计数变量 + 循环里加一 + 超线就撤。

### 练习题

**练习 1**：用 while 倒数打印 10、9、8……1，最后打印 `launch!`。

> 提示：i 从 10 起，循环里 print、减 1，条件 i >= 1。倒计时结束了再打印。

**练习 2**：1+2+3+…，加到**和第一次超过 500** 为止，打印加到了第几个数、和是多少。

> 提示：两个变量：s 攒和、i 数个数；while s <= 500；循环里 i 加一、s 加 i。循环后 s、i 各是什么？动笔模拟两圈就明白。

**练习 3**：打印 1~20 中所有**不是 5 的倍数**的数（用 while + 0x12 的自造余数）。

> 提示：余数配方 x - int(x / 5) * 5；余数不等于 0 才打印。

**参考答案**：

练习 1：
```basic
10 i = 10
20 while i >= 1
30   print i
40   i = i - 1
50 wend
60 print "launch!"
70 end
```

练习 2：
```basic
10 s = 0
20 i = 0
30 while s <= 500
40   i = i + 1
50   s = s + i
60 wend
70 print "n="; i
80 print "sum="; s
90 end
```

（跑完 n=32、sum=528。32 个数加起来首次破 500。）

练习 3：
```basic
10 i = 1
20 while i <= 20
30   if i - int(i / 5) * 5 <> 0 then print i
40   i = i + 1
50 wend
60 end
```

### 本章小结

- `while 条件 ... wend`：先检查后执行，不知道圈数的循环。
- 循环体必须推动条件变化，否则死循环。
- `while 1` 恒真；系统有 100000 步超时保护保命，但正式程序要能自己结束。
- 等待类任务标配：计数超时（t 加一，超线就撤）。
- 圈数已知用 for，圈数看情况用 while。

## 0x31 字符串：文字的加工厂
你好！今天我们来学习字符串的专题课。前面已经会存串、拼串了，今天上全套设备：量长度、切片子、数变文、文变数，还要解决一个高级问题——**没有数组，怎么携带一整队数据**。

### 0x31.1 拼接与铁律复习
串与串用 `+` 拼接；**串与数不混算**（铁律0x02 立的）：

```basic
10 name$ = "memoria"
20 msg$ = "hello, " + name$ + "!"
30 print msg$
40 print "version " + str$(2)
50 end
```

第 40 行：数字 2 想拼进文字，先过海关——`str$(2)` 把数字变成串 `"2"`。**str$ 是"数字→文字"的签证处**。

### 0x31.2 val：回程船票
反方向，`val(s$)` 把文字变回数字：

```basic
10 a$ = "123"
20 x = val(a$) + 1
30 print x
40 end
```

打印 `124`。没 val 的话，"123" 只是一串字符，不能拿来算。

一个贴心设定：val 遇到**不是数字的串，返回 0，不报错**。`val("abc")` 得 0。程序不会炸，但你要知道 0 可能是"没转出来"，别把它当真数据。

这俩函数在哪最有用？**网络**。服务器发回来的响应体 r$ 是文字，里面的数字要算术就得 val——0x61 HTTP 客户端见真章。

### 0x31.3 len：量长度（按字符量）
`len(s$)` 返回串的长度——**按字符量，汉字算 1 个字符**：

```basic
10 print len("abc")
20 print len("好")
30 end
```

打印 `3` 和 `1`。**按字符量**——中文一个汉字算 1 个字符，跟"人眼数出来的字数"一致。老版本按字节量（1 汉字 = UTF-8 3 字节），新固件已改为按字符，写程序不用再数 3 的倍数。

实用推论：**每行程序上限 96 字节**（约 32 个汉字，按字节上限），print 打 10 个汉字没问题。

### 0x31.4 切片三兄弟：left$ / right$ / mid$
从一串文字里切出一部分：

| 函数 | 意思 | 例子 |
|---|---|---|
| `left$(s$, n)` | 从**左**取 n **字节** | `left$("hello", 2)` → `"he"` |
| `right$(s$, n)` | 从**右**取 n **字节** | `right$("hello", 2)` → `"lo"` |
| `mid$(s$, start, len)` | 从第 start **字节**起取 len 字节 | `mid$("hello", 2, 3)` → `"ell"` |

特别注意 `mid$` 的 start **从 1 数起**——人从 1 开始数数，这次机器顺着你。三个函数都按**字节**切，切英文怎么切都行；切汉字记住"1 汉字 = 3 字节"，掐头去尾要按 3 的倍数掐，不然会切出半个字的乱码。

切片最常用的场景：**检查开头**。比如验证文件名是不是 `img` 打头：`if left$(name$, 3) = "img" then ...`。

### 0x31.5 chr$：数字变一个字符
`chr$(n)` 把 0~255 的数字变成对应的单字节字符：

```basic
10 print chr$(65)
20 print chr$(97)
30 print chr$(48)
40 end
```

打印 `A`、`a`、`0`。数字和字符的对照表叫 ASCII 码，几个常用号背下来有好处：**65=A，97=a，48=0，32=空格**。大写和小写差 32（65 和 97），这个"差 32"是老牌程序员的肌肉记忆。

> **彩蛋：ASCII 是 1963 年的老古董**
> ASCII（美国信息交换标准代码）1963 年定稿，安排编码时 engineers 把 "a" 定为 97、"A" 定为 65——中间空出 32 个号给标点。为什么大小写差 32？据说当年想让"大小写互换"能用一个开关位实现（65+32=97，二进制只差一位）。一个 60 多年前的设计决定，你今天在 BASIC 里按 chr$ 还在受益。另外注意：我们的工具箱里只有 chr$（数字变字符），没有反向的"字符变数字"函数——所以那张对照表，值得背。

### 0x31.6 没有数组？字符串当背包
BASIC **没有数组**（想一口气装 100 个数？没有 `a[1]`、`a[2]` 这种东西）。但有个传统妙招：**把一串数据装进一个字符串，用分隔符隔开**，像背包里塞一排口袋：

```basic
10 bag$ = "apple,banana,pear"
```

三个水果名，逗号隔开。要取第 2 个？——先自己造一个"查找器"，这正好是本章压轴实战。

### 0x31.7 压轴实战：自造"查找器"
BASIC 没有"在串里找字"的现成函数（别的语言叫 Instr/Find），我们**自己造一个**：在 s$ 里找 w$ 出现的位置，找不到报 0。

思路：从第 1 个字节起，逐个位置试——每个位置切出一块 len 长的片段，跟目标比一比；比中了就记下位置。

```basic
10 s$ = "hello memoria"
20 w$ = "memo"
30 sl = len(s$)
40 wl = len(w$)
50 found = 0
60 i = 1
70 while i + wl - 1 <= sl
80   if mid$(s$, i, wl) = w$ then found = i
90   i = i + 1
100 wend
110 print found
120 end
```

打印 `7`（"memo" 从第 7 个字节开始）。

逐块讲解：

- 60 行：i 是"试到第几个字节了"，从 1 开始。
- 70 行：只要"目标长度还能塞得下"（i + wl - 1 不超过总长），就继续试。
- 80 行：从 i 起切出 wl 字节，跟 w$ 比对，比中就记录位置。
- 90 行：挪一个字节继续试。

**没工具有什么了不起，for/while + mid$ + 比较，十行造一个**——这就是编程思想第 2.5 节说的"没有工具自己打一把"。这个查找器你以后会在很多程序里反复用（找分隔符切背包、找关键词……）。

### 练习题

**练习 1**：把 "basic" 倒着打印出来（输出 `cisab`）。提示太少？再给一条：从最后一个字节开始，一个一个往左挪，用 chr$……不对，用 mid$ 切出来拼。

> 提示：`while i >= 1`，从 i = 5 开始，每圈拼上 `mid$(w$, i, 1)`，i 减 1。（英文 1 字母 1 字节，才敢这么切。）

**练习 2**：检查变量 f$（文件名）是否以 `cfg` 结尾，是打印 `yes` 否打印 `no`。

> 提示：right$(f$, 3) = "cfg"。

**练习 3**：串 n$ = "42"，把它转成数字后**平方**，再把结果拼进文字打印成 `result=1764`。

> 提示：val 转进去，算完 str$ 转出来。一来一回都要过海关。

**练习 4**：统计串 s$ = "banana" 里字母 a 出现的次数。

> 提示：循环 i 从 1 到 len(s$)，每圈切 `mid$(s$, i, 1)`，跟 "a" 比，比中计数器加一。

**参考答案**：

练习 1：
```basic

30 out$ = ""
40 while i >= 1
50   out$ = out$ + mid$(w$, i, 1)
60   i = i - 1
70 wend
80 print out$
90 end
```

练习 2：
```basic

20 if right$(f$, 3) = "cfg" then print "yes" else print "no"
30 end
```

练习 3：
```basic
10 n$ = "42"
20 x = val(n$)
30 r = x * x
40 print "result=" + str$(r)
50 end
```

练习 4：
```basic
10 s$ = "banana"
20 c = 0
30 i = 1
40 while i <= len(s$)
50   if mid$(s$, i, 1) = "a" then c = c + 1
60   i = i + 1
70 wend
80 print c
90 end
```

（打印 3。）

### 本章小结

- 串拼串用 `+`；串数换算：`str$` 去、`val` 回，val 遇非数字得 0。
- `len` 按字符量：汉字算 1 个字符。
- 切片：left$ / right$ / mid$（start 从 1 起，按字符切，汉字安全）。
- `chr$(65)`="A"；大写小写差 32；没有反向函数。
- 没有数组：串 + 分隔符当背包，自造查找器来切片。
- 自造工具三件套：while 推进 + mid$ 切片 + 比较。

## 0x41 绘图：屏幕是画布
你好！今天换个大场地——离开文字区，去整块屏幕上作画。今天的语句就 8 个，但组合起来能画国旗、画图表、做动画。学完这章，你的程序从"打字机"升级成"画板"。

### 0x41.1 坐标系：先看懂地图
屏幕分辨率 **480×320**（宽 480，高 320，ILI9488 横向屏），每个点（像素）用 `(x, y)` 定位：

- 原点 `(0, 0)` 在**左上角**；
- x 向**右**增大，y 向**下**增大。

**注意：跟数学课的坐标系不一样！** 数学课 y 向上，屏幕 y 向下——因为老显示器是从上到下一行行扫描点亮的，惯例就这么传下来了。画图时心里默念："y 大 = 越靠下。"

### 0x41.2 color 与 clear：笔和橡皮
```basic
10 color 255, 0, 0
20 clear
30 end
```

- `color r, g, b`：调**当前画笔颜色**。三个数各 0~255，分别是红、绿、蓝的剂量——三原色混色：红+绿=黄，红+蓝=紫（品红），绿+蓝=青，全 0=黑，全 255=白。之后画的任何东西都用这支笔。
- `clear`：整屏清黑（橡皮）。

> 自己调颜色的直觉：0 是"一点不加"，255 是"拉满"。多试几组（255,128,0 是橙色；100,100,100 是深灰），两分钟就有手感。

### 0x41.3 六个画图语句
| 语句 | 写法 | 效果 |
|---|---|---|
| `text` | `text 10, 20, "hi"` | 在 (10,20) 打文字（用当前色） |
| `pixel` | `pixel 5, 5` | 点亮 1 个像素 |
| `line` | `line 0, 0, 100, 50` | 从 (0,0) 到 (100,50) 画一条线段 |
| `rect` | `rect 10, 10, 50, 30` | 画矩形**边框**：左上 (10,10)，宽 50 高 30 |
| `fill` | `fill 10, 10, 50, 30` | 同上，但**实心**填充 |
| `circle` | `circle 120, 80, 40` | 以 (120,80) 为圆心、半径 40 画**圆框** |

rect/fill 的后两个参数是**宽和高**，不是右下角坐标——新手高频坑，标红记住。

### 0x41.4 实战一：画个小房子
```basic

20 fill 120, 120, 80, 70
30 color 150, 60, 40
40 line 110, 120, 160, 70
50 line 160, 70, 210, 120

80 end
```

拆解：棕色实心矩形当房身（120,120 起，宽 80 高 70）；两条红线当屋顶斜边（从屋檐两头汇聚到屋脊 (160,70)）；深灰实心小矩形当门。跑一遍，再改改数字看每行各管哪块——**改数字观察变化**是学绘图最快的方法。

### 0x41.5 实战二：进度条（绘图版）
0x21 打过文字版进度条，绘图版更有内味：

```basic
10 color 0, 200, 80
20 for i = 1 to 20
30   fill 10, 100, i * 15, 20
40   for d = 1 to 3000
50   next d
60 next i
70 end
```

每圈把进度条加宽 15 像素重画一遍（fill 盖上去就是"变长"），中间那个空转小循环是**拖时间**用的——马上讲。

### 0x41.6 动画原理与"空转延时"
动画的原理一句话：**画一帧 → 擦掉 → 画下一帧 → 循环**。人眼每秒看 20 帧以上就动起来了。

问题来了：机器跑得飞快，一秒能画几千帧，太快只能看成一团糊。需要"每帧之间歇口气"——但 BASIC **没有等待语句**。土办法：**空转循环**，让程序白跑几万圈消耗时间：

```basic
for d = 1 to 3000
next d
```

什么都不干，纯耗时间。机器快慢不同，3000 这个数自己调：太慢改小，太快改大。

上正菜——**弹跳球**：

```basic
10 x = 20
20 y = 20
30 dx = 3
40 dy = 2
50 while 1
60   clear
70   color 255, 220, 0
80   circle x, y, 5
90   x = x + dx
100  y = y + dy
110  if x > 315 then dx = 0 - dx
120  if x < 5 then dx = 0 - dx
130  if y > 235 then dy = 0 - dy
140  if y < 5 then dy = 0 - dy
150  for d = 1 to 3000
160  next d
170 wend
180 end
```

讲解：

- x、y 是球心位置；dx、dy 是**每帧的位移**（速度）。
- 主循环每帧：清屏 → 画球 → 更新位置 → 撞墙调头 → 延时。
- 撞墙逻辑：x 超过右边界（320 减掉球半径），速度取反（`0 - dx` 把 3 变 -3，球就往回弹）。
- `while 1` 永动——这个程序就是靠保险丝或你手动退出的，玩着玩的程序无所谓。
- 速度写 `0 - dx` 而不是 `-dx`：负号直接跟变量在某些写法里容易歧义，`0 -` 一百个稳。

**先擦再画**的顺序不能反——反了就是每帧都在旧图上叠新球，画出一串毛毛虫。动画两大定律：**擦要擦干净，画要画得勤**。

> **彩蛋：直线的算法是 1962 年的网红**
> line 语句背后跑的是 Bresenham 算法——1962 年 IBM 工程师 Bresenham 为绘图仪设计的，只用整数加减就能算出最直的斜线，快得惊人。60 多年过去了，从你的掌机到 3A 游戏显卡，画直线的底层数学还是它。你每画一条线，都在向 1962 年致敬。

## 0x51 gosub、include、goto：把代码管起来
你好！今天我们来学习程序的"收纳术"。程序一长，问题就来了：同一段代码到处复制、改一处忘三处、几千行糊成一团。今天的三件工具——gosub、include、goto——就是治这个的。

### 0x51.1 gosub / return：代码的抽屉
`gosub` 是 "go subroutine"（去子程序）：跳到某行干活，干到 `return` **原路跳回来**，接着跑下一句。

```basic
10 print "main start"
20 gosub 100
30 print "main end"
40 end
100 print "  sub: did something"
110 return
```

输出：

```
main start
  sub: did something
main end
```

执行轨迹：10 → 20 跳去 100 → 110 return **跳回 20 的下一行** 30 → 40 结束。像去银行办业务：取号（gosub 100）→ 柜台办事（100~110）→ 办完回到大堂（return 回原处）→ 继续干自己的事。

**gosub 和 goto 的区别就在"回不回来"**：goto 是一去不回头的搬家；gosub 是出差，办完事回来。这就是"子程序"（别的语言叫函数）的雏形。

### 0x51.2 子程序的摆放规矩
子程序通常放**程序末尾**，主程序用 `end` 挡住去路，防止"误入"：

```basic
10 print "1. joke  2. tip"
20 print "choose?"
30 input c
40 if c = 1 then gosub 200
50 if c = 2 then gosub 300
60 print "bye"
70 end
200 print "  why did wifi break up with cable?"
210 print "  too attached."
220 return
300 print "  tip: semicolon glues, comma spaces."
310 return
```

选 1 跳 200 行讲笑话，return 回来打 bye 结束。注意 70 行的 `end` 是**安全门**：没有它，选完 1 后 return 回 50 行继续往下走，会一头栽进 200 行的笑话区再讲一遍——程序结尾挡一块 end，是行号 BASIC 的标准工事。

gosub 还能**嵌套**：子程序里再 gosub 另一个，return 按先进后出逐层弹回（栈式管理），像下楼的电梯一站站倒回去。放心用，别超过十层。

### 0x51.3 为什么子程序是大事
三笔账：

1. **复用**：画坐标轴的代码写一次，五个程序段都 gosub 它。
2. **单点修改**：改 bug 只改抽屉里那一份，不用全程序搜抄了八遍的代码。
3. **主程序可读**：main 区只剩"调谁"不剩"怎么干"，30 行看懂整个流程。

从今天起立个规矩：**同一段代码出现第二次，就提成子程序**。

### 0x51.4 include：把另一本册子订进来
`include "lib.bas"` 在**编译期**把另一个 .bas 文件的全部行合并进来——同号行以 include 进来的为准（覆盖）。比喻：装订时把另一本册子整本订在这本后面，页码冲突就听新册子的。

典型用法：把常用子程序（查找器、等待 WiFi、画框）放进 `lib.bas`，每个新程序开头 `include "lib.bas"`，家底直接继承。注意被 include 的文件也放在 TF 卡 `/mem_fat/scripts/` 目录。

```basic
10 include "lib.bas"
20 gosub 500
30 end
500 print "this is from lib!"
510 return
```

（如果 lib.bas 里已有 500 行，则以 lib.bas 的为准——所以**库文件和主程序的行号最好分开规划**，比如库用 500~899，主程序用 10~499。）

### 0x51.5 goto：半禁用的猛兽
`goto 100` 无条件跳到 100 行，**不回头**。它有个特殊待遇：**每轮运行时系统会提示一次**注意事项（易死循环、逻辑混乱）——这是解释器在提醒你：能不用就不用。

为什么 goto 名声差？1968 年计算机科学家 Dijkstra 写了封著名的信《Go To Statement Considered Harmful》（goto 语句有害论），指出满屏乱跳的 goto 会把程序搅成"面条"——没人能看懂执行流。这场论战催生了"结构化编程"，也就是本书开篇课讲的三大结构。**历史结论：goto 保留给大骨架跳转**（比如主菜单循环回菜单页），日常逻辑全部用 if/for/while/gosub 组织。

### 0x51.6 实战：菜单程序（标准骨架）
综合本章，一个可扩展的菜单骨架，值得收藏：

```basic
10 while 1
20   clear
30   print "=== MENU ==="
40   print "1. calc  2. joke  0. quit"
50   input c
60   if c = 0 then end
70   if c = 1 then gosub 200
80   if c = 2 then gosub 300
90   if (c <> 0) * (c <> 1) * (c <> 2) then print "??"
100 wend
200 input a
210 input b
220 print "sum="; a + b
230 return
300 print "  haha."
310 return
```

主循环 while 1 永动转菜单；选 0 end 退出；选别的 gosub 去各功能区；非法输入打问号。**菜单 = while 1 + input + 分发 gosub**——这个骨架是行号 BASIC 的万能模板，你的第一批"应用"都能从它长出来。

- `gosub 行号` ... `return`：出差模式，办完回来；栈式可嵌套。

- 同段代码出现第二次就提子程序。
- `include "lib.bas"` 编译期合并，同号覆盖；库行号要跟主程序分区规划。
- goto 半禁用（每轮提示）；能三大结构解决就不 goto。
- 菜单万能骨架：while 1 + input + gosub 分发。

## 0x61 WiFi 与网络：把掌机接上互联网
你好！今天是个大日子：我们让掌机**联网**。从这一章起，你的程序不再是一座孤岛——能拉网页、传数据、跟服务器聊天。今天学的三件套 httpget / httppost / httpstat，就是将来"畅聊"聊天应用的全部地基。

### 0x61.1 连 WiFi：系统管网，程序只读状态
**WiFi 由系统统一管理**——跟手机一样，在系统设置里有 WiFi 扫描列表，点选连接、输密码，都是设置页的事。程序**不允许也不应该自己连网**（老写法 `wifi "ssid","pass"` 是保留兼容语句，联网程序调用会被忽略并提示）。那程序怎么知道连没连上？读系统预注入的**环境变量**：

| 预注入变量 | 说明 |
|---|---|
| `wifi_ssid$` / `wifi_pass$` | 系统当前连接的 WiFi |
| `ap_ssid$` / `ap_pass$` | 系统开出的 AP 热点（系统设置里自定义） |
| `ble_name$` | 蓝牙名称（系统设置里配置） |

```basic
10 if wifistat() = 0 then print "wifi 未连，去系统设置连网" : end
20 print "当前WiFi: "; wifi_ssid$
30 end
```

- `wifistat()`：查询函数，**1 = 已连上，0 = 没连上**。
- `wifi_ssid$` 这类变量**随系统连接状态自动更新**，程序开机直接读就行。

连完必须查状态——代码要养成"**联网必验**"的习惯，别把没网当有网往下跑。要更稳，用0x22 的"计数超时"骨架等连接。

### 0x61.2 httpget：伸手要内容
```basic
10 httpget "http://192.168.1.100/api/hello", r$
20 print r$
30 end
```

- `httpget "网址", r$`：向网址发 GET 请求（"把内容给我"），服务器回的**响应体**存进串变量 r$。
- r$ 上限 **8KB**——服务器回太大就装不下，设计接口时要控制内容尺寸。
- 网址目前**只支持明文 http://**（HTTPS 后补）。所以别用它传密码等敏感信息，路上是裸奔的。

### 0x61.3 httpstat：问一句"成了吗"
`httpstat()` 返回**上一次 HTTP 请求的状态码**：

- `200`：成功（HTTP 世界里 200 = OK）；
- `404`：没这个页面；`500`：服务器出错；
- `0`：压根没请求成功/连接失败。

```basic
10 httpget "http://192.168.1.100/api/hello", r$
20 s = httpstat()
30 if s = 200 then print r$ else print "http err "; s
40 end
```

标准姿势：**先 httpget，后查 httpstat，200 才用 r$**。三步走，一步不少。这个"验后再用"跟 wifi 的"联网必验"是同一套纪律。

> **彩蛋：404 是个房间号？**
> 流传最广的都市传说：CERN 实验室 404 房间是网络工作组所在地，找不到文件就报"404"。其实官方说法很无聊：4xx = 客户端错（你输错网址），404 = "Not Found"，编号是分类流水号。但传说太好听，大家都懒得辟谣——你看，互联网自己就是最好的故事会。

### 0x61.4 httppost：主动交作业
`httpget` 是"我要"，`httppost` 是"我给"：

```basic
10 httppost "http://192.168.1.100/api/send", "hello from memoria", r$
20 if httpstat() = 200 then print "sent" else print "fail "; httpstat()
30 end
```

- 第 2 个参数 b$（这里是字符串字面量）**原样上传**，服务器收到一串字节（octet-stream 类型）。
- 第 3 个参数 r$ 接服务器回复，跟 httpget 一样。

**一拉一推，就是全部网络交互**：聊天应用 = httppost 发消息 + httpget 拉新消息；天气应用 = httpget 拉天气；上报传感器 = httppost 发读数。0x83 综合项目就是这一章的毕业考试。

### 0x61.5 一个完整的"求职"客户端
把本章 + 超时骨架 + val/str$ 串起来：

```basic
20 t = 0
30 while wifistat() = 0
40   t = t + 1
50   if t > 50000 then print "wifi timeout" : end
60 wend
70 httpget "http://192.168.1.100/api/num", r$
80 if httpstat() <> 200 then print "http err "; httpstat() : end
90 n = val(r$)
100 print "server says: "; n * 2
110 end
```

服务器回一个数字文本（比如 `"21"`），客户端 val 转成数字、翻倍打印。**拉回来 → 验状态 → 转格式 → 加工 → 输出**，五步流水线，一切网络程序都是它的变体。

## 0x62 record 与 play：给程序装上耳朵和嘴巴
你好！今天我们来学习声音。之前所有交互都靠"看"，今天加入"听"和"说"：`record` 让掌机竖起耳朵录音，`play` 让它开口放音。学完你就能做录音机、留言机——这也是"畅聊"语音消息的地基。

### 0x62.1 record：录音（会阻塞）
```basic
10 record "/mem_fat/v1.wav", 3
20 print "done"
30 end
```

`record "路径", 秒数`：对着麦克风录一段声音，存成 WAV 文件到 TF 卡。规则三条：

1. **时长 1~60 秒**，示例录 3 秒。
2. 录的是 **16kHz 单声道 16bit 的 WAV**——掌机自动包好格式，你只管给路径。
3. **阻塞**：录音那几秒，程序站着不动——你在录音，它不干别的。

"阻塞"是个重要概念：**这行不执行完，下一行不开始**。所以 record 前最好先 print 一句"recording..."，不然用户不知道机器在干嘛。

### 0x62.2 play：放音（不阻塞）
```basic
10 play "/mem_fat/v1.wav"
20 print "playing in background"
30 end
```

`play "路径"`：播放 WAV（MP3 也认）。跟 record 相反——**后台播放，不阻塞**：声音还在响，程序已经跑到下一行。适合"音乐当背景，界面继续动"的场景。

一表对比记住：

| | record | play |
|---|---|---|
| 干嘛 | 麦克收音存 WAV | 放 WAV/MP3 |
| 阻塞 | 是（1~60 秒站住） | 否（后台响） |
| 产物 | TF 卡上多一个 .wav | 听见声音 |

### 0x62.3 实战：录音回放机
```basic
10 print "recording 3s..."
20 record "/mem_fat/v1.wav", 3
30 print "playing..."
40 play "/mem_fat/v1.wav"
50 print "program end (sound keeps)"
60 end
```

录 3 秒、放 3 秒。注意 50 行打印后程序其实已经结束了，但声音还在后台放——这就是"不阻塞"。

> **彩蛋：16kHz 是什么音质**
> 电话的采样率是 8kHz，能听清就是不太甜；16kHz 是"清清楚楚但别要求 hi-fi"的水平。WAV 本身是微软/IBM 搞的 RIFF 格式，声音原样存不压缩——所以大，所以简单，所以任何设备都认。你的掌机选 WAV 全链路，走的就是"笨一点但谁都吃得消"的路线。

### 0x62.4 实战：简易留言机
文件名用变量拼，就能留好几条：

```basic
10 n = 1
20 while n <= 3
30   print "message "; n; " recording..."
40   record "/mem_fat/note.wav", 3
50   print "playing back..."
60   play "/mem_fat/note.wav"
70   n = n + 1
80 wend
90 end
```

循环三轮：录 3 秒、放 3 秒。想存**不同文件名**？串拼接：`"/mem_fat/note" + str$(n) + ".wav"`——第 n 条存 note1.wav、note2.wav……（上机时把 40、60 行的路径换成这个拼法试试，练 str$。）

一个诚实的边界提醒：BASIC 目前**没有"读任意文件内容进变量"的语句**（record 只会写 WAV、play 只会放 WAV）。所以"录音后把 WAV 内容发到网上"这种操作，纯 BASIC 现在做不到，需要系统层支持——知道边界在哪，就不浪费力气撞墙。

### 练习题

**练习 1**：录 5 秒并播放，录之前和录之后各打印一句提示。

> 提示：print + record + print + play。

**练习 2**：连录两段（v1.wav、v2.wav），然后连放两遍。文件名用串拼。

> 提示：`"/mem_fat/v" + str$(i) + ".wav"`，i 跑 1 和 2；两段 record + 两段 play。

**练习 3**（设计题，不用写完整代码）：做一个"开机三次提示音"程序：每次开机连播三遍提示音再结束。想一想：播放不阻塞，三遍连播会怎样？要不要在 play 之间加延时？

> 提示：不阻塞 = 三条 play 会几乎同时响（叠音）。土办法：play 之间塞空转循环拖几秒；或者干脆接受叠音当和弦。设计没有标准答案，但要**知道后果再选**。

**参考答案**：

```basic
30 print "recorded, now play"

50 end
```

```basic
30 i = 2

```

### 本章小结

- `record "路径", 秒`：录 WAV，1~60 秒，**阻塞**。
- `play "路径"`：放 WAV/MP3，**后台不阻塞**。
- 阻塞/不阻塞是程序节奏的核心概念。
- 文件名可串拼（str$）实现多条存取。
- 边界：BASIC 没有通用文件读取，别设计"读文件进变量"的方案。

## 0x71 uart、ble、gpioin、system：摸得着的硬件
你好！今天我们来学习掌机的"手脚"。前面会画会说会联网了，今天补上最后几件硬件家伙：调试口、蓝牙、读引脚、重启。学完这章，BASIC 的全部家当你就见完了。

### 0x71.1 uart：往电脑喊话的专线
```basic
10 uart "boot ok"
20 uart "value=" + str$(42)
30 end
```

`uart "文本"` 把文字发到 **USB 串口**。掌机插上电脑，打开串口调试工具（波特率按固件说明），就能看到这些话。print 是打给用户看的，uart 是打给**开发者**看的——程序跑岔了，沿途多埋几条 uart，串口一看就知道死在哪一步。这招叫"打点调试"，是每个老程序员兜里最旧的瑞士军刀。

### 0x71.2 ble：蓝牙透传
```basic
10 ble "hello from memoria"
20 end
```

`ble "文本"` 通过**蓝牙**把文字发给已连接的上位机（电脑/手机上的蓝牙调试工具）。配套玩法：手机蓝牙串口 App 连上掌机，就能收发文字——不给 WiFi 也能隔空喊话。前提是**上位机已连接**，没连接就发了个寂寞。

### 0x71.3 gpioin：读引脚电平
```basic
10 x = gpioin(4)
20 print "gpio4="; x
30 end
```

`gpioin(引脚号)` 读某个 GPIO 引脚的电平，返回 **0 或 1**。引脚上接按钮、门磁、光敏电阻……电平就随外界变化。轮询它，程序就"摸得到"外面的世界。

```basic
10 while 1
20   x = gpioin(4)
30   clear
40   color 0, 255, 0
50   if x = 1 then text 20, 100, "ON" else text 20, 100, "OFF"
60   for d = 1 to 20000
70   next d
80 wend
90 end
```

这是一个"引脚状态监视器"：每 0.1 秒刷一次 GPIO4 的电平，高就显示 ON，低就显示 OFF。**轮询 = while 1 + 读 + 刷屏 + 延时**，跟弹跳球一个骨架，只是"位置更新"换成了"读外界"。

### 0x71.4 system：重启
```basic
10 system "reboot"
```

`system "reboot"` 让整台掌机重启（当前唯一支持的动作）。测试稳定性、脚本演示"自复位"时用。**慎用**：重启是核弹级动作，没保存的现场都没了。

### 0x71.5 实战：门磁报警器（思路版）
把 13.3 的监视器升级：GPIO4 接门磁开关，门开（电平变 1）就大字报警：

```basic
10 while 1
20   x = gpioin(4)
30   clear
40   if x = 1 then color 255, 0, 0 else color 0, 255, 0
50   if x = 1 then text 40, 100, "DOOR OPEN!" else text 40, 100, "safe"
60   for d = 1 to 20000
70   next d
80 wend
90 end
```

color 跟着状态换色、字号级警示。想更凶？加 `ble "door open!"` 往手机蓝牙推一条——**读引脚 + 分支 + 通知**，一个物联网雏形就成了。

**练习 1**：开机后用 uart 打三行启动日志：`boot`、`memoria basic ok`、`version 2`，然后打印到屏幕 `booted`。

> 提示：三行 uart + 一行 print。

- `uart "文本"`：串口调试专线，打点排错神器。

## 0x72 好习惯与保命机制
你好！今天不讲新语句——语法你已全见完。今天讲"内功"：怎么少踩坑、出错了怎么查、程序怎么写别人（和三个月后的你）看得懂。这章的内容，价值不比前面任何一章低。

### 0x72.1 三道保命机制（系统替你上的保险）
| 机制 | 内容 | 你要做的 |
|---|---|---|
| 步数上限 | 每程序最多执行 100000 步，超限强制终止，报"超时保护" | 别依赖它收尾，循环要能自己结束 |
| 包校验 | .msp 安装包 CRC32 校验，损坏/被篡改的包拒绝落盘 | 从正规渠道装程序 |
| 跳转语义 | goto/gosub/return/循环跳转后，目标行**真正被执行**（不是"跳过了"） | 知道这个语义，读代码不迷路 |

### 0x72.2 没有注释语句，怎么给代码留字条
很多语言有注释语句（REM 或 //），程序里写给人看、机器跳过。**BASIC 没有 rem**。那怎么"留字条"？三招：

1. **起好变量名**：`sum`、`name$`、`retry_count` 自带说明，`a`、`b2`、`zz` 是天书。
2. **uart 打点**：关键位置 `uart "step1: loaded"`，串口日志就是活的注释。
3. **小步快跑**：一次只加三五行就运行一次——代码短到不需要注释，也是一种注释。

### 0x72.3 出错了怎么查：打点调试法
程序行为不对，按这个顺序查：

1. **二分打点**：在程序中间和末尾各加一行 `uart "check1"`、`uart "check2"`。跑一次：都出现——毛病在后半段；只有 check1——毛病在前半段。再在可疑段中间打点……几轮就夹出病灶。
2. **打印变量**：疑心哪个变量，就 `print` 或 `uart` 它的值，看它"什么时候变得不对劲"。
3. **怀疑顺序**：先怀疑自己的**条件边界**（> 写成 >=、off by one），再怀疑自己的**赋值顺序**（先除后乘？先覆盖后使用？），最后才轮到"是不是机器的问题"——99.9% 不是。

### 0x72.4 排版三律
- **一行一件事**：冒号少用，顶多连两句明显配套的。
- **行长 96 字节**：约 32 个汉字，超长写不进去；长内容拆变量装。
- **循环体缩进**：机器不看，人看。书上的习惯就是你的习惯。

### 0x72.5 找茬实战：这段程序有 4 处毛病
```basic
10 print "how old are you?"
20 input age
30 msg$ = "age:" + age
40 if age > 0 and age < 150 then print "ok"
50 for i = 1 to 3
60   print i
70 while age > 0
80   age = age - 1
90 end
```

先自己找 5 分钟，再看答案。

**答案**：

1. **第 30 行：串数混算**——`"age:" + age` 违反铁律，要 `str$(age)`。
2. **第 40 行：`and` 不存在**——本语言没有逻辑关键字，要 `(age > 0) * (age < 150)`。
3. **第 50 行：for 没配 next**——循环开出去没人收口，跑到 while 就乱套。补一行 `next i`。
4. **第 70 行：while 没配 wend**——同上，缺收口；而且 90 行的 end 在 while 体内，就算补了 wend 逻辑也是歪的。

修正版：

```basic
10 print "how old are you?"
20 input age
30 msg$ = "age:" + str$(age)
40 if (age > 0) * (age < 150) then print "ok"
50 for i = 1 to 3
60   print i
70 next i
80 while age > 0
90   age = age - 1
100 wend
110 end
```

四类毛病——**混算、不存在的关键字、循环没收口、结构嵌套错位**——占新手错误的八成。

### 0x72.6 自查十条（发布前过一遍）
1. 每个循环都有收口吗（next / wend）？
2. 串和数有没有裸混算？
3. and/or/not 换成乘加减了吗？
4. if 都是完整一行吗？
5. then 数字跳转的目标行存在吗？
6. 主程序末尾有 end 挡子程序吗？
7. 死循环有出口吗（别靠保险丝）？
8. 联网必验（wifistat/httpstat）了吗？
9. 变量名见名知意吗？
10. 边界试过吗：输入 0、负数、最长串？

### 练习题

**练习 1**：指出毛病：`10 if x = 5 and y = 3 then print "yes"`——并改正。

> 提示：and。乘起来。

**练习 2**：指出毛病：`10 for i = 1 to 5 : print i`（就这一行）——并改正。

> 提示：for 缺 next。冒号句里收口：`10 for i = 1 to 5 : print i : next i`。

**练习 3**：这段想"打印 3、2、1"，实际会打印什么？为什么？怎么改？

```basic
10 i = 3
20 while i > 0
30   print i
40 wend
```

> 提示：循环体里没有推动条件变化的语句——i 永远是 3，死循环到保险丝拉闸。改：30 行后加 `i = i - 1`。

**参考答案**：

练习 1：
```basic

```

练习 2：
```basic
10 for i = 1 to 5 : print i : next i
```

练习 3：无限打印 3（直到"超时保护"强制终止）。修正：
```basic
10 i = 3
20 while i > 0
30   print i
40   i = i - 1
50 wend
```

### 本章小结

- 三道机制：步数 100000、CRC32、跳转语义。
- 无 rem：好名字 + uart 打点 + 小步快跑。
- 调试三板斧：二分打点、打印变量、先怀疑自己。
- 四大新手错误：混算、and/or、循环没收口、结构错位。
- 发布前过"自查十条"。

## 0x81 综合项目一：猜数字
你好！从今天起连做三个毕业项目。第一个：**猜数字**——电脑随机想一个 1~100 的数，你来摇杆调数猜，它提示"大了/小了"，猜中报次数。前面学的 input、if、while、rnd 全要上场。

### 0x81.1 先想流程（动笔不写码）
用开篇课的思想拆一拆：

- **顺序**：开局出题 → 进入问答循环 → 猜中收尾。
- **循环**：没猜中就一直问——圈数不知道，**while**（条件：还没猜中）。
- **分支**：每轮比较，猜中了翻旗子；没中给提示。

流程图只有一页：**出题 → 问 → 比 → 提示/收尾 → 回到问**。想清楚再写，比边写边改快十倍——这是"编程思想"值钱的地方。

### 0x81.2 完整程序
```basic
10 n = int(rnd() * 100) + 1
20 c = 0
30 win = 0
40 print "== guess 1-100 =="
50 while win = 0
60   print "your guess:"
70   input g
80   c = c + 1
90   if g = n then win = 1
100  if g < n then print "try bigger"
110  if g > n then print "try smaller"
120 wend
130 print "correct! tries="; c
140 end
```

### 0x81.3 逐行讲解
- **10 行**：出题。随机数配方造 1~100，存进 n。
- **20 行**：c 是计次器，从 0 起步。
- **30 行**：win 是**旗子变量**——0 表示"还没猜中"，1 表示"中了"。旗子是 while 循环的常用搭档：条件写 `while win = 0`，读起来像人话："还没赢就继续问"。
- **60~70 行**：问一轮。input 用摇杆调数（±1/±10），调到想猜的数按下确认。
- **80 行**：本轮计次。
- **90 行**：猜中就把旗子竖起来。**注意这行不打印**——打印放到循环外面，"中了"的消息只该说一次。
- **100/110 行**：没中就给方向提示。这两行只在 g ≠ n 时动嘴。
- **130 行**：出循环后报战绩：几次猜中。

**这个程序里有个微妙的好设计**：三个 if 排排站（等于/小于/大于），互相不干扰，逻辑一目了然。新手爱写"if 嵌 if"炫技，其实**平铺三个 if 往往更清楚**——简单直接是行号 BASIC 的美德。

### 0x81.4 上机后的改造练习
跑通之后，别停——**改造是编程进步最快的方式**：

**改造 1**：限制 7 次机会，超限打印 `game over` 并公布答案。

> 提示：加 `if c >= 7 then win = 1`（旗子换个含义：结束），循环后再分支打印是赢是输。参考：
>
> ```basic
> 10 n = int(rnd() * 100) + 1
> 20 c = 0
> 30 win = 0
> 40 print "== guess 1-100, 7 tries =="
> 50 while win = 0
> 60   print "your guess:"
> 70   input g
> 80   c = c + 1
> 90   if g = n then win = 1
> 100  if c >= 7 then win = 2
> 110  if g < n then print "try bigger"
> 120  if g > n then print "try smaller"
> 130 wend
> 140 if win = 1 then print "correct! tries="; c
> 150 if win = 2 then print "game over, n="; n
> 160 end
> ```
>
> （win 从"旗子"升级成"结果码"：1 赢 2 输——状态多起来就用数字编码，好习惯。）

**改造 2**：距离提示——差 5 以内提示 `hot!`，否则按远近提示。

> 提示：`d = abs(g - n)`；`if d <= 5 then print "hot!"` 放在三个 if 之后再判断。

**改造 3**：用 gosub 把"问一轮"提成子程序，主循环瘦身。

> 提示：变量全局共享，子程序里直接改 g、c、win 都生效。

### 本章小结

- 随机出题：`int(rnd() * 100) + 1`。
- 旗子变量控制 while：`while win = 0`。
- "中了"的消息放循环外，只说一次。
- 结果一多，旗子升级为结果码。
- 学完项目必改造——改的过程才是长本事的过程。

## 0x82 综合项目二：屏幕保护——弹跳球加星空
你好！毕业项目二：做一个**屏保动画**——深蓝夜空里星星闪烁，一颗黄球满屏弹跳。这是0x41 弹跳球的豪华版，学会"多层画面"的组织方式。

### 0x82.1 设计拆解
画面分两层：

- **背景层**：每帧撒 30 颗随机星星（白点 pixel）。
- **前景层**：1 颗弹跳球（黄圆）。

每帧的工序：**清屏 → 画星星 → 画球 → 更新球位置 → 撞墙检查 → 延时**。这个"工序清单"就是主循环体——先列清单再写码，依然是好习惯。

### 0x82.2 完整程序
```basic
10 x = 20
20 y = 20
30 dx = 3
40 dy = 2
50 s = 0
60 while 1
70   clear
80   color 200, 200, 200
90   for i = 1 to 30
100    pixel int(rnd() * 320), int(rnd() * 240)
110  next i
120  color 255, 220, 0
130  circle x, y, 5
140  x = x + dx
150  y = y + dy
160  if x > 315 then dx = 0 - dx
170  if x < 5 then dx = 0 - dx
180  if y > 235 then dy = 0 - dy
190  if y < 5 then dy = 0 - dy
200  for d = 1 to 3000
210  next d
220 wend
230 end
```

### 0x82.3 讲解与细节
- **70 行 clear**：每帧全清——星星每帧重撒（位置每帧随机变），产生"星星闪烁"效果，一举两得。
- **80~110 行**：灰色画笔撒 30 颗星。坐标用 `int(rnd() * 320)` / `int(rnd() * 240)` 落在整个屏幕——随机数配方第三次出场了。
- **120~130 行**：黄色画球。**画笔颜色管理**：每层画前先 color，层次感靠颜色切换。
- **140~190 行**：位置更新 + 撞墙调头，0x41 原封不动搬来——**写好的骨架就该这么复用**。
- **200~210 行**：空转延时。嫌快改大、嫌慢改小。
- **50 行的 s**：留了个计次器没用——改造练习会用到，先占位。

### 0x82.4 上机后的改造练习
**改造 1**：球带"运动轨迹残影"——不清屏，改用黑 fill 在旧位置抹掉球再画新位置。

> 提示：把 clear 换成 `color 0,0,0 : fill x - 6, y - 6, 12, 12`（抹旧），但星星就不能重撒了——改成开场撒一次星星、之后只抹球画球。参考思路：
>
> ```basic
> 60 color 200, 200, 200
> 70 for i = 1 to 30
> 80   pixel int(rnd() * 320), int(rnd() * 240)
> 90 next i
> 100 while 1
> 110   color 0, 0, 0
> 120   fill x - 6, y - 6, 12, 12
> 130   color 255, 220, 0
> 140   circle x, y, 5
> 150   x = x + dx
> ...(后续同前)
> ```
>
> （先撒星后进循环——循环外只干一次的事就放循环外。）

**改造 2**：加第二颗球（红），两球独立速度独立弹跳。

> 提示：再开 x2、y2、dx2、dy2 四个变量，同款两行更新 + 四行撞墙。变量一多你会发现"起名的艺术"——s1、b1x、b2x 这类前缀命名这时候开始有用了。

**改造 3**：用上 50 行的 s——每 100 帧换一次球色（比如按 s 轮换三色）。

> 提示：s = s + 1 每帧加一；`if s - int(s / 300) * 300 < 100 then color 255,220,0 else if s - int(s / 300) * 300 < 200 then ...`（自造余数配方第四次数立功）。

### 本章小结

- 多层画面 = 每帧按"背景 → 前景"顺序画。
- 每帧重撒随机星 = 闪烁特效（清屏的副产品利用）。
- 局部重绘（抹旧画新）替代全屏 clear，是动画进阶技法。
- 变量多起来，前缀命名（b1x、b2x）救你的命。

## 0x83 综合项目三：网络小报
你好！毕业项目三：**网络小报**——连上 WiFi，从服务器拉一段今日小报文本，屏幕排版显示；断网、坏接口都有体面的处理。这是0x61 的毕业考，也是将来"畅聊"客户端的雏形。

### 0x83.1 设计拆解
工序清单：

1. 连 WiFi（带计数超时）；
2. httpget 拉文本；
3. httpstat 验货（非 200 报错退出）；
4. 把响应体排版画到屏幕（text 分行）；
5. 结束。

三个出口：超时、HTTP 错、成功——每个出口都要"体面"（有提示、能收尾），这是职业程序和练习程序的分水岭。

### 0x83.2 完整程序
```basic
10 print "waiting wifi..."
20 t = 0
30 while wifistat() = 0
40   t = t + 1
50   if t > 50000 then print "wifi timeout" : end
60 wend
70 httpget "http://192.168.1.100/news.txt", r$
80 if httpstat() <> 200 then print "http err "; httpstat() : end
90 color 0, 255, 120
100 clear
110 text 10, 10, "== DAILY =="
120 text 10, 40, left$(r$, 30)
130 text 10, 60, mid$(r$, 31, 30)
140 text 10, 80, mid$(r$, 61, 30)
150 text 10, 120, "done."
160 end
```

### 0x83.3 讲解与细节
- **10 行**：先打提示再等网——凡是要等的操作，先告诉用户"在忙"，别让人以为死机。这条叫"**别让用户干等**"原则。
- **20~60 行**：计数超时等连接（0x22 骨架第三次上岗）。WiFi 由系统设置连好，程序只等 `wifistat()` 变 1。**骨架复用率是检验你学没学会的标尺**。
- **80 行**：验货。`<> 200` 不对劲就报错码退出——错误码显示出来，排查时省一大截（是 404 还是 0？故事完全不同）。
- **110~140 行**：排版。响应体 r$ 当"30 字符一行"的报纸切三行显示。left$ 切首行、mid$ 切后续——0x31 切片三兄弟全部到场。切片按**字符**，中文也不会切出半个字。

### 0x83.4 上机后的改造练习
**改造 1**：失败重试 3 次——把 httpget + 验货包成子程序，主流程 for 3 次调用。

> 提示：子程序里判断成功就设旗子 ok=1，主循环查旗子决定停不停。

**改造 2**：屏报轮播——拉回来的文本 10 秒一换行滚动。

> 提示：切片起点从 1、31、61 往后推，用变量 p 控制：`text 10, 40, mid$(r$, p, 30)`；p = p + 30，外层 while 1 + 空转延时；p 超过 len(r$) 就归 1。

**改造 3**（思考题）：把小报升级成"留言板"：掌机用 httppost 发一句话、httpget 拉全部留言显示。想想：服务器需要哪些接口？发的话怎么带上你的名字？（串拼接 `n$ + ": " + msg$`。）——想完这个，你就已经设计出"畅聊"的掌机端原型了。它正是下一个大工程：多端聊天应用"畅聊"的起点。

### 本章小结

- 网络程序三个体面出口：超时、HTTP 错、成功。
- 先提示再等待；错误码要显示出来。
- 文本排版 = left$/mid$ 按行宽切片（按字符切，中文安全）。
- 发 + 拉 = 聊天应用的原型。

**毕业了。** 17 章，你从 `print "hello"` 走到了联网客户端。接下来没有教材了——去写你自己的程序吧。卡住了就回翻对应章节，或者翻附录。祝玩得开心。

## 附录 D：已知边界（写程序前必读）

- **字符串与数字不混算**：`str$` / `val` 过海关。
- **没有**：数组、自定义函数（def fn）、rem 注释、and/or/not、`^` 幂符、mod 取余、asc（字符→数字）、Instr（串查找）、wait/延时语句、通用文件读写。
- and/or 用算术组合（乘/加）；mod 用 `x - int(x/n)*n`；延时用空转循环。
- `input a$` 支持中文（自动调起拼音输入法，见 `docs/IME-SPEC.md`）；`input x` 摇杆调值。
- HTTP 仅明文 `http://`（HTTPS 后补），响应体 ≤8KB。
- record 单段 1~60 秒且阻塞；play 后台不阻塞。
- 变量名大小写不敏感（官方风格全小写）；行号唯一，同号覆盖。
- .bas 文件放 TF 卡 `/mem_fat/scripts/`，PRGM 模式运行。

## 附录 E：从 .bas 到上架（软件链路）

```
BASIC 源码（.bas 文本）
    → 打包成 .msp 安装包（50 字节头 + 源码正文，CRC32 校验）
    → 上架 manifest.json（软件源清单）
    → STORE 商店下载安装到 /mem_fat/scripts/
    → PRGM 模式运行（解释执行）
```

你写的 .bas 就是程序本体；.msp 只是"信封"。想把自己程序分享给别人：打包上架，别人商店一按就装好。
