# Memoria OS 接线施工图（WIRING）

> 照本文件焊接即可，无需读代码。所有引脚号唯一来源：`components/memoria_drivers/include/drivers_config.hpp`；分配依据见 `GPIO-ALLOC.md`。两者冲突时以 drivers_config.hpp 为准并回报桥上。

---

## 0. 总则（焊前必读）

1. **供电**：锂电池 → TP4056（B+/B−）→ OUT+ 串拨动开关 → 整机 3.3V 域。TP4056 的 OUT 接核心板 5V/3V3 由核心板 LDO 降压，或直接用 3.3V LDO——**所有模块 VCC 一律 3.3V**（除 TP4056 本体）。
2. **共地**：所有模块 GND 与电池负极、核心板 GND 单星汇聚一点，避免地环路。
3. **天线禁区**：核心板天线端约 15×5mm 区域周围 **5mm 内禁止金属件、禁止铺铜、禁止走线**。
4. **Strapping 引脚**（开机采样，勿接上拉器件）：GPIO0（BOOT）、GPIO3、GPIO45、GPIO46。GPIO46 已用于灯带数据，灯带 DIN 不含上拉、串 330Ω~1K 保护电阻即可。
5. **USB**：GPIO19/20 为 USB D−/D+，核心板 USB-C 口直插烧录/供电，**这两脚不接任何外设**。
6. **BOOT 键**：用核心板自带 BOOT 键进下载模式，无需外焊。

## 2. 分模块接线表（按焊接顺序）

### 2.1 电源链（安卓式电源管理，2026-10-06 定版）
| 连接 | 说明 |
|------|------|
| 电池红 → TP4056 B+，电池黑 → B− | 503450 级 3.7V 锂电 |
| TP4056 OUT+ → 核心板 5V（或经 3.3V LDO） | **常供电，无物理开关**；"关机"= 固件深度睡眠（微安级），"开机"= 长按电源键 RTC 唤醒 |
| TP4056 OUT− → 核心板 GND | 共地点 |
| 电池+ → R1 100K → 采样节点；采样节点 → R2 100K → GND；节点 → GPIO4 | **节点并一颗 100nF 到 GND**（ADC 源阻抗高，无电容读数偏低） |
| USB-C（TP4056 模块自带）从外壳侧壁开孔伸出 | 充电口 |

**电源键（侧键①）**：独立引线接 **GPIO2**（RTC 域，唯一空闲，可深度睡眠唤醒），另一端接 GND（按键按下=拉低）。
- 上电即开机：任何时刻插电/电池供电 → 核心板直接启动进桌面。
- 长按 ≥2s（运行中）：弹出电源菜单【关机 / 重启 / 取消】。
- 关机：`esp_deep_sleep_start()`，唤醒源 = GPIO2（EXT0 下降沿）。
- 深度睡眠中长按电源键 ≥1s：RTC 唤醒 → 重启进桌面（≈ 安卓开机）。
- 短按（<2s）：忽略（防误触）。
- 注意：深度睡眠仅保留 RTC 域，PSRAM/屏幕掉电；NVS/mem_priv 数据不丢。

### 2.7 键盘矩阵 6×10（60 键；电源键已独立，见 §2.1）
- 每行：该行 **10 颗键的左脚并联**一条线 → 对应行线。
- 每列：该列 **6 颗键的右脚并联**一条线 → 对应列线。
- 键位布局（固件定义，焊键帽时对照）：

```
行    C0    C1    C2    C3    C4    C5    C6    C7    C8    C9
R1   (空)  F1    F2    F3    F4    F5    F6    F7    灯带   ⌫
R2   1     2     3     4     5     6     7     8     9     0
R3   q     w     e     r     t     y     u     i     o     p
R4   a     s     d     f     g     h     j     k     l     ;
R5   ⇧     z     x     c     v     b     n     m     ,     .
R6   CAP   CTRL  VOL−  VOL+  空格   ←     →     ↓     ↑     ⏎
```

- **R1 行 C0 原 ON 键已移出矩阵**：改为独立侧键①接 GPIO2（安卓式电源键，见 §2.1），该位不焊键（或留作 F8 自定义，固件映射待定）。
- 行线去向：R0=R1行、R1=R2行 … R5=R6行 → MCP#1 GPA0~5。
- 列线去向：C0~C3 → MCP#1 GPB0~3；C4~C9 → MCP#2 GPA0~5。
- **二极管两案（防多键串扰）**：
  - **A 案（不焊）**：60 键直连。单/双键正常，Shift+字母+第三键成矩形时会偶发多出一个错字。焊工量最小。
  - **B 案（推荐）**：每键串一颗 1N4148——**键右脚 → 二极管阳极，阴极 → 列线**（电流方向 列→行 导通）。60 颗，彻底防幽灵键。
  - 两案固件通用，先焊 A 案可开机，后续可补。

### 2.8 键盘灯带 WS2812 ×2（串成一条 12 珠链）
- GPIO46 → 330Ω → 灯带① DIN；灯带① DOUT → 灯带② DIN。
- 灯带 VCC 接 3.3V，GND 共地。两条分别贴键盘上边沿/下边沿（各 6 珠）。

## 3. 焊完上电自检（对照 GPIO-ALLOC §5）

| 步 | 动作 | 预期 |
|----|------|------|
| 1 | 接电池（TP4056 红灯亮）或插 USB-C 充电线 | TP4056 红灯亮 = 充电回路 OK；**常供电，无需开关** |
| 2 | 等待上电 | 屏背光亮、桌面/启动画面出现，**不无限重启**（Z1 死锁修复验证点） |
| 3 | 看 A 桌面右上角电池图标 | 显示百分比 ≈ 实测电压（电量永远 0% = ADC 接线错） |
| 4 | 拨摇杆 | 焦点在桌面格子间移动（X/Y 反了就互换 VRx/VRy 线） |
| 5 | 按任意键 | 终端输入字符；按 F1~F7 进对应模式 |
| 6 | 按 R1 行"灯带"键 | 键盘灯带亮/切换档位（全黑 = 灯带链路检查 330Ω 与 DIN 方向） |
| 7 | **长按电源键（侧键① GPIO2）≥2s** | 弹电源菜单【关机 / 重启 / 取消】；选关机 → 屏灭（深度睡眠）；再长按 ≥1s → 唤醒回桌面 |
| 8 | 进 MUSIC 播 sample/ 下 mp3 | 出声 = I2S 链 OK |
| 9 | 拔 TF 再插回 | 字库加载失败报错 = TF 座接触不良，重焊 |

## 4. 已知坑位提示

- **GPIO33~37 绝对不接东西**（Octal PSRAM 内部占用，接了会崩）。
- 摇杆 VCC 必须 3.3V：5V 供电时 ADC 超量程，中位值漂移。
- MCP #2 的 A0 忘接 3.3V → 两颗芯片同地址 0x20，键盘列 C4~C9 全乱。
- 二极管方向焊反（B 案）→ 该键永远无反应，逐键排查时按自检表第 5 步。
- 灯带方向：DIN 箭头朝进数据侧；接反整条不亮。
