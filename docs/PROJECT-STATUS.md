## 一、项目一句话

ESP32-S3 N16R8 上的自研掌机操作系统：内核、窗口、文件系统、脚本引擎、BASIC 解释器、应用商店全部手写，不依赖任何 UI 框架。最终形态是一台能送人的小电脑——礼物背景见 README「项目由来」。

## 六、风险与缺口

- **.m4a 测试素材缺失**：外网 https 被本机网络掐断，demo 下载失败，需用户拷卡。
- **真机实测全未做**：模拟器/编译全绿 ≠ 上板可用，P0 清单是当前最大不确定项。
- **README GPIO 表仍是迁移前旧值**（摇杆 36/37、TF CS 5、I2S 4/3/2、电池 39）——本次重写必须修正为迁移后（7/5、17、18/21/15、4）。
- 3D 模型 `外壳.123dx` 为专有格式，需确认是否可导出 STL。
