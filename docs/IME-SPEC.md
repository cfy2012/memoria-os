# Memoria OS 掌机中文输入法规格（IME-SPEC）

> 版本：v1.0（2026-10-04 拍板）· 状态：规格定稿，固件线待排期
> 需求来源：用户拍板——输入法像软件一样能更新；碰到输入框自动弹出；拼音选字；BASIC 新增汉字类型

## 1. 总体形态

- **系统级输入法组件**：固件内常驻引擎 + TF 卡码表数据分离。
- **可更新**：码表 `/ime/pinyin.bin` 独立文件，TF 卡替换即生效（带版本头校验）；引擎随固件组件版本化更新。
- **自动弹出**：所有 BASIC 程序 `input a$` / `input name@` 触发系统输入面板，无需程序干预。

## 2. 交互与键位（用户拍板版）

输入面板 = 拼音编辑行 + 候选条（fn 键行上方，显示 4 个候选汉字及对应键提示）。

| 按键 | 功能 |
|---|---|
| `a`~`z` | 键入拼音字母（实时过滤候选） |
| **F1~F4** | 选当前批 4 个候选汉字上屏 |
| **F5** | 候选往前翻一批 |
| **F6** | 候选往后翻一批 |
| 退格 | 有拼音时删字母；拼音空时上屏区删一个汉字 |
| **Ctrl+Shift 同时按** | 中文 / 英文模式切换（用户拍板 2026-10-04，替代早先 F8 方案） |
| 确认键 | 无拼音时结束输入（相当于回车）；有拼音时上屏编辑行原字母 |

- 候选不足 4 个时 F1~F4 按实际个数生效。
- 模式默认拼音；Ctrl+Shift 切英文后按键直接上屏字母，再切回继续拼音。
- **输入法状态系统变量**（用户拍板）：系统维护布尔环境变量 `ime_cn`——1（true）=中文、0（false）=英文，Ctrl+Shift 切换时自动更新，BASIC 程序可读（与 wifi_ssid$ 同批预注入）。

## 3. 码表（已生成，随 TF 卡分发）

- 文件：`/ime/pinyin.bin`，**PYIME1** 格式，6763 字（GB2312 一二级全集），63 KB。
- 排序：一级字库（常用 3755 字）在前、二级在后——顺序扫描时常用字优先出候选。
- 多音字全收录（例：行 xing/hang/heng、长 chang/zhang、的 de/di）。
- 生成器：`tools/gen_pinyin.py`（pypinyin，D 盘环境）；后续字频/词库扩展走 PYIME2（预留字频字段）。
- 固件引擎：顺序扫表 + 前缀匹配（C++ 实测 <1ms），候选按表序输出。

## 4. BASIC 语言：中文内嵌字符串（用户拍板："嵌到 char 里，跟原程序本来就有一样"）

- **不新增类型、不新增后缀**（@/# 提案作废）——汉字能力直接内嵌 `$` 字符串类型：

| 能力 | 语义 |
|---|---|
| `let a$ = "你好"` / `print a$` | 源码直接写中文，零特殊处理 |
| `input a$` | 自动调起输入法面板，直录中文 |
| `len(a$)` | 按**字符数**计数（纯英文=字节数，老程序零差异） |
| `left$/mid$/right$` | 按**字符边界**切取，绝不切断汉字 |
| 内部存储 | 仍为 UTF-8 字节——TF 卡/HTTP 链路零转换，与 chat 服务端天然兼容 |

- 兼容性：存量程序仅用 ASCII 时字符=字节，行为完全不变；含中文时旧按字节语义本就会切烂汉字，新语义是修正。
- BASIC-LANGUAGE.md v1.4 §2/§4.4 已同步此语义；原提案 §4.5 独立汉字类型撤销。

## 5. 固件落地清单（components/memoria_basic + ime）

1. `input` 语句接输入法面板（默认拼音模式，Ctrl+Shift 切中英）；面板 UI 复用现有 fn 键行范式；系统布尔变量 `ime_cn` 预注入（1=中文 0=英文，切换自动更新）。
2. 拼音引擎：读 `/ime/pinyin.bin`（PSRAM 整表加载），前缀匹配 + 批次翻页。
3. **字符串 UTF-8 感知改造**（内嵌 char，不新增类型）：len/left/mid/right 按字符处理；源码串字面量、input、print 全链路中文支持。
4. 顺带修复 ime.cpp 历史遗留：候选条高亮逐位右漂（字符宽度计算错误）。
5. 码表版本头校验（PYIME1 魔数 + 条目数），损坏文件拒绝加载并提示。

## 6. 里程碑

- M1（随下版固件批次）：input 调起 + 拼音选字 + 码表加载——掌机能打中文发 chat。
- M2（后续）：字频/词库 PYIME2、联想词、BASIC `@` 类型全量函数族。
