# Memoria OS · 全零件尺寸手册（照此画壳）

> 版本：2026-10-03 · 与 `HARDWARE-DIMENSIONS.md`（叠层/引脚）、`HARDWARE-BOM.md`（采购）同源
> 单位：mm · 尺寸来源：市售模块通用规格（淘宝常见款），**「实」= 必须卡尺实测后覆盖**，「定」= 已定版
> 用途：你自己画外壳（123D Design）时，按本表查每个零件的长×宽×高、接口方向、开孔要求

---

## 〇、画壳流程（建议顺序）

1. **先排厚度**：下表「厚度关键件」里最高的那条决定壳厚（摇杆 32 / 屏幕 8 / 喇叭 10 / 核心板下凸 7 / 键盘 3.75 / 电池 5）。
2. **再排平面**：按层级表（顶部→主板→底仓→侧壁）把每件放进去，元件凸起不得侵占隔板。
3. **最后开孔**：屏幕窗、键孔、摇杆孔、麦克孔、侧壁缝（TF/SD/USB/开关/音量）、透音孔、螺丝孔。

## 一、厚度关键件（决定整机厚度，先看）

| 件 | 高度 | 说明 |
|----|------|------|
| KY-023 摇杆 | 杆帽立起**总高 ~32**（自 PCB 面），板上件 ~10 | 想薄壳就把它独立穿顶（PCB 放顶层、杆帽从面板 Ø16 孔露出 ~7.5）；不想穿顶就整体按 40mm 级设计 |
| ILI9488 屏幕（含排针） | 6~8（实） | 排针朝下，实测可压到 6~7 |
| 喇叭 | 厚 5~10 + 腔体 2~3（实） | 用方形纸盆喇叭时按实 |
| 锂电 505080 | 5 | 软包，可微弯 1~2 |
| 核心板（背焊） | 芯片朝底仓**下凸 ~7** | 占底仓顶空间，下方不摆件 |
| 键盘层 | 轻触键 2.5 + 键帽内嵌 ~1.25 = **3.75** | 键帽不按时与面板齐平，按下行程 0.25 |
| 2× MCP23017 | 3.2（DIP28 高） | 主板层内收纳 |
| TP4056 | 3~4 | 主板层内 |

## 待卡尺实测（定稿前必须覆盖）

1. ILI9488 模块**含排针实际高度**（6~8 → 直接影响整机厚）
2. 喇叭实际厚度 + 腔体余量（5~10 + 2~3）
3. KY-023 杆帽立起**实际总高**（32 为市售典型）
4. 电池 505080 **实际厚度**（5）与标称容量复核（市售 4500~5200mAh）
5. 核心板含排针实际高度（~5.5）与背焊下凸量（~7）
6. 洞洞板孔径实际值（0.9~1.0）
