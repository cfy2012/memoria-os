### 1.3 GPIO48 次级 MOS 极性——**不是新增，1.4.0 里就已经是对的**

不要重做。1.4.0 的 `power.cpp` 已是：

```c

     * 深睡时 GPIO48 输出高保持（S3 deep sleep 数字 IO 状态保留）。 */
```
