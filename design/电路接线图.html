② 分模块接线（按焊接顺序）

2.1 电源链 先焊

电池红 → TP4056 B+503450 级 3.7V 锂电
电池黑 → TP4056 B−—
TP4056 OUT+ → 拨动开关 → 核心板 5V/3V3SS12D00 柄从侧壁伸出；3.3V 由核心板 LDO 降压
TP4056 OUT− → 核心板 GND共地点（单星汇聚）
电池+ → R1 100K → 采样节点 → R2 100K → GND；节点 → GPIO4节点并 100nF 到 GND
TP4056 自带 USB-C 从外壳侧壁开孔伸出充电口（10×4 孔）
所有模块 VCC 一律 3.3V（除 TP4056 本体）；全机 GND 单星汇聚一点，避免地环路。

2.8 键盘矩阵 6×10（60 键）

每行该行 10 颗键的左脚并联一条线 → 对应行线 R0~R5
每列该列 6 颗键的右脚并联一条线 → 对应列线 C0~C9
行线去向R0=R1行 … R5=R6行 → MCP#1 GPA0~5
列线去向C0~C3 → MCP#1 GPB0~3；C4~C9 → MCP#2 GPA0~5
二极管 A 案（不焊）60 键直连。单/双键正常，三键成矩形时偶发错字，焊工量最小
二极管 B 案（推荐）每键串 1N4148：键右脚 → 二极管阳极，阴极 → 列线（电流 列→行 导通），彻底防幽灵键
两案固件通用，先焊 A 案可开机，后续可补。

2.10 ESP32 大核心板 45×28 独立小舱 · 面板 X 52~99 / Y 60~90（开舱 47×30 + 盖子）

③ 电源树

电源路径：电池 → TP4056（充电管理）→ OUT+ → 拨动开关 → 核心板 5V → LDO 3.3V → 全机模块。所有模块 VCC 一律 3.3V，除 TP4056 本体。

⑤ 焊完上电自检

步动作预期
1拨开关前插 USB（充电线）TP4056 红灯亮 = 充电回路 OK
2拨开关上电屏背光亮、桌面/启动画面出现，不无限重启
3看桌面右上角电池图标百分比 ≈ 实测电压（永远 0% = ADC 接线错）
4拨摇杆焦点在桌面格子间移动（X/Y 反了互换 VRx/VRy 线）
5按任意键终端输入字符；F1~F7 进对应模式
6按 ON 旁「灯带」键键盘灯带亮/切换档位（全黑 = 查 330Ω 与 DIN 方向）
7进 MUSIC 播 sample/ 下 mp3出声 = I2S 链 OK
8进 REC 录音再播放回放有录音 = INMP441 链 OK（真机验证点）
9拔 TF 再插回热插拔日志 card removed/inserted + 挂载恢复（#30 验证点）

⑥ 已知坑位

  • GPIO33~37 绝对不接东西（Octal PSRAM 内部占用，接了会崩）。
  • 摇杆 VCC 必须 3.3V：5V 供电时 ADC 超量程，中位值漂移。
  • MCP #2 的 A0 忘接 3.3V → 两颗芯片同地址 0x20，键盘列 C4~C9 全乱。
  • 二极管方向焊反（B 案）→ 该键永远无反应。
  • 灯带方向：DIN 箭头朝进数据侧；接反整条不亮。
  • 麦克风数据脚是 GPIO16（不是 45）：45 为 strapping 脚，勿接上拉器件。
  • 核心板天线端 5mm 内禁金属/禁铺铜/禁走线。
